Section 1 gave you the machinery for computing with a Markov chain: the one-step probabilities $p_{ij}=\mathbf{P}(X_{n+1}=j\mid X_n=i)$, the $n$-step probabilities $r_{ij}(n)=\mathbf{P}(X_n=j\mid X_0=i)$, and the Chapman–Kolmogorov recursion $$r_{ij}(n)=\sum_k r_{ik}(n-1)\,p_{kj}$$ that grinds one out of the other (L17 slide 2). This section asks a different kind of question — a qualitative one, answered by looking at the transition diagram rather than by multiplying matrices:

Where does the chain end up? Which states will it visit forever, which will it abandon, and does the answer to "where am I at time $n$?" settle down as $n$ grows?

The classification we build here — recurrent vs. transient states, recurrent classes, periodic vs. aperiodic classes — is exactly what the steady-state convergence theorem needs as a hypothesis. Section 3 will compute the steady-state probabilities $\pi_j$; this section decides whether they exist. That order is not negotiable: a balance-equation calculation performed on a chain that fails the hypotheses returns a number that is not a limit of anything (§2.4 shows a chain where the balance equations have a perfectly nice solution $\pi=(1/4,1/2,1/4)$ while $r_{ij}(n)$ oscillates forever).

Interpretation. Everything in this section depends only on which $p_{ij}$ are positive, never on their values. Erase all the numbers from the transition diagram, keep the arrows, and every classification question below can still be answered. That is why the whole section is graph theory wearing a probabilist's hat (B&T §7.2, p. 349: "the classification of a state is determined by the arcs of the transition probability graph, not by the values of the probabilities").

2.1 Accessibility, recurrence, transience

Fix a chain with state space $\{1,\dots,m\}$ and one-step probabilities $p_{ij}$. Two states are related by "can I get there from here?", and everything follows from that relation.

Definition (accessibility; B&T §7.2, p. 348). State $j$ is accessible from state $i$ if there is a positive-probability path from $i$ to $j$ — that is, if $r_{ij}(n)>0$ for some $n\ge 0$. Equivalently, there is a sequence of states $i=i_0,i_1,\dots,i_n=j$ with $p_{i_0i_1}p_{i_1i_2}\cdots p_{i_{n-1}i_n}>0$, i.e. a directed path in the transition diagram. We write $$A(i)=\{\,j : j \text{ is accessible from } i\,\}$$ for the set of states reachable from $i$. Since $n=0$ is allowed, always $i\in A(i)$.
Definition (recurrent / transient; L17 slide 3). State $i$ is recurrent if, starting from $i$, and from wherever you can go, there is always a way of returning to $i$. Formally: $i$ is recurrent if $i\in A(j)$ for every $j\in A(i)$. If $i$ is not recurrent — i.e. if there exists some $j\in A(i)$ with $i\notin A(j)$ — then $i$ is transient.

Unpack the quantifiers, because they are the whole content of the definition. $i$ is transient exactly when there is one escape route: a state $j$ you can reach from $i$ from which you can never come back. $i$ is recurrent when no escape route exists: every place the chain can wander to still has a road home.

Recipe (classify a state).
  1. Erase the numbers. Keep only the arcs with $p_{ij}>0$. Nothing below uses the values.
  2. Compute $A(i)$. Start at $i$, follow arrows forward, add every new state you meet, and stop when nothing new appears. (This is a graph search; on a diagram you do it by eye.)
  3. Look for a leak. If some $j\in A(i)$ cannot get back to $i$, then $i$ is transient. Otherwise $i$ is recurrent, and its recurrent class is exactly $A(i)$.
  4. If recurrent, get the period $d=\gcd\{n\ge 1: r_{ii}(n)>0\}$ = the gcd of the lengths of all cycles through $i$ (§2.3). A single self-loop anywhere in the class forces $d=1$.
In practice you never do this state by state: you spot the closed blobs on the diagram (those are the recurrent classes) and everything else is transient.

Solution

(a) Classification. Run the recipe on each state. Read the arcs off Fig. 2.2: $$\begin{array}{ll} 1\to 5\ (0.2),\ 1\to 2\ (0.5),\ 1\to 8\ (0.3) &\quad 2\to 1\ (0.4),\ 2\to 6\ (0.6)\\ 3\to 3\ (0.2),\ 3\to 4\ (0.5),\ 3\to 5\ (0.3) &\quad 4\to 3\ (1)\\ 5\to 5\ (0.4),\ 5\to 3\ (0.6) &\quad 6\to 6\ (0.3),\ 6\to 7\ (0.7)\\ 7\to 6\ (1) &\quad 8\to 4\ (0.5),\ 8\to 2\ (0.5)\\ 9\to 7\ (1) \end{array}$$ Each row sums to 1, as it must (verified in computes/g5_s2.py, key warmup_rowsums_ok).

State 3. Follow arrows: $3\to4$, $3\to5$, and from 4 only back to 3, from 5 only to 3 or itself. Nothing new ever appears, so $A(3)=\{3,4,5\}$. Is there a leak? From 4 we reach $A(4)=\{3,4,5\}\ni 3$; from 5 likewise. Every state accessible from 3 can return to 3, so 3 is recurrent, and by the same computation so are 4 and 5. Their common accessible set $\{3,4,5\}$ is a recurrent class.

State 6. $6\to7$, $7\to6$, plus the self-loop, so $A(6)=\{6,7\}=A(7)$, no arc leaves the pair, and 6 and 7 are recurrent, forming a second class $\{6,7\}$.

State 1. $A(1)=\{1,2,3,4,5,6,7,8\}$ (from 1 you can reach 5 and hence the whole left class, and via $2\to 6$ the whole right class; only 9 is unreachable). Now look for a leak: $6\in A(1)$ but $A(6)=\{6,7\}$ does not contain 1. So 1 is transient. The same escape route $\cdots\to 6$ makes 2 and 8 transient (both have $A=\{1,2,3,4,5,6,7,8\}$). And 9 is transient: $A(9)=\{6,7,9\}$, and from 6 there is no arc back to 9 — 9 has an outgoing arrow but no incoming one at all.

Answer to (a): recurrent classes $\{3,4,5\}$ and $\{6,7\}$; transient states $1,2,8,9$ (computed independently by graph search in computes/g5_s2.py, keys warmup_recurrent_classes, warmup_transient_states).

(b) A specific path. This is the multiplication rule plus the Markov property — no classification needed. Write the event as a chain of conditionals: $$\mathbf{P}(X_1=2,X_2=6,X_3=7\mid X_0=1) =\mathbf{P}(X_1=2\mid X_0=1)\,\mathbf{P}(X_2=6\mid X_0=1,X_1=2)\,\mathbf{P}(X_3=7\mid X_0=1,X_1=2,X_2=6),$$ which is the multiplication rule (G1 §2) applied inside the conditional universe $\{X_0=1\}$. By the Markov property each factor forgets everything but the most recent state: $$=p_{12}\,p_{26}\,p_{67}=0.5\times 0.6\times 0.7=\boxed{0.21}.$$ Every term is a single arc of Fig. 2.2, which is why questions of this shape are answered "by inspection".

(c) A four-step transition. Now the intermediate states are not specified, so we need $r_{27}(4)$. Two equivalent routes to the answer.

Route 1 — enumerate the paths. Starting at 2 we must land on 7 after exactly four steps. From 2 the only arcs are $2\to1$ and $2\to6$; tracing all continuations that end at 7 leaves exactly three paths: $$\begin{aligned} 2\to1\to2\to6\to7:&\quad 0.4\times0.5\times0.6\times0.7=0.0840,\\ 2\to6\to6\to6\to7:&\quad 0.6\times0.3\times0.3\times0.7=0.0378,\\ 2\to6\to7\to6\to7:&\quad 0.6\times0.7\times1\times0.7=0.2940. \end{aligned}$$ These are disjoint events (different state sequences), so add them: $$r_{27}(4)=0.0840+0.0378+0.2940=\boxed{0.4158}.$$

Route 2 — the recursion. Equivalently $r_{27}(4)=\sum_k r_{2k}(3)p_{k7}$, i.e. the $(2,7)$ entry of the fourth matrix power $P^4$. Computed with numpy.linalg.matrix_power in computes/g5_s2.py (key warmup_Q2_r27_4): $0.415800$ — agreeing with the path enumeration to all printed digits.

Interpretation (what the warm-up is really showing). Push $n$ further and the transient states empty out. From state 2, the row of $P^{200}$ is $$r_{2\cdot}(200)=(0,\;0,\;0.094595,\;0.047297,\;0.047297,\;0.476948,\;0.333863,\;0,\;0),$$ i.e. zero on every transient state, and the same to six decimals at $n=201$ (keys warmup_r2_row_n200, warmup_r2_row_n201). The mass splits between the two classes: solving the absorption system of §4 gives $\mathbf{P}(\text{end in }\{6,7\}\mid X_0=2)= 30/37=0.810811$ and hence $7/37=0.189189$ for $\{3,4,5\}$; each class then distributes its share according to its own steady-state vector, $(0.5,0.25,0.25)$ on $\{3,4,5\}$ and $(10/17,7/17)=(0.588235,0.411765)$ on $\{6,7\}$ (§3 computes these). Indeed $0.810811\times0.588235=0.476948$ and $0.189189\times0.5=0.094595$, matching the numbers above exactly (key warmup_from2_predicted_row). The limit exists here but depends on the starting state — start at 9 and you land in $\{6,7\}$ with probability 1. That is failure mode number one of §2.4.
Gotcha. Three traps, all of them classic exam losses.
  • Accessibility is one-way. $j\in A(i)$ does not give $i\in A(j)$. State 9 reaches 7; 7 never reaches 9.
  • "Transient" does not mean "rarely visited at first". State 1 in Fig. 2.2 may be visited many times before the chain escapes — transience is about the infinite horizon.
  • A state with a self-loop can still be transient (state 2 in Figure 2.5(b) below has $p_{22}=0.4$ and is transient), and a recurrent state need not have a self-loop. The self-loop is irrelevant to recurrence; it matters only for the period.
Property (transient states are visited finitely often; L16 slide 7, B&T §7.2 p. 350). If $i$ is transient then $\mathbf{P}(X_n=i)\to 0$ as $n\to\infty$, and with probability 1 the chain visits $i$ only finitely many times.

Derivation (the lecture asserts this; here is the argument). Let $i$ be transient. By definition there is a state $j\in A(i)$ with $i\notin A(j)$, and since $j$ is reachable from $i$ there is a path of some length $n_0$ from $i$ to $j$; let $q=r_{ij}(n_0)>0$ be its probability. Now suppose the chain is at $i$ at some time. In the next $n_0$ steps it moves to $j$ with probability at least $q$, and from $j$ it can never return to $i$. Hence $$\mathbf{P}(\text{the chain ever returns to } i\mid \text{currently at } i)\le 1-q<1 .$$ Call this bound $\rho=1-q$. By the Markov property, each "attempt" to return is an independent trial with success probability at most $\rho$, so the number $N$ of visits to $i$ counted from a time at which the chain is at $i$ is stochastically dominated by a geometric random variable: $$\mathbf{P}(N\ge k)\le \rho^{\,k-1},\qquad k=1,2,\dots$$ Therefore $\mathbf{P}(N=\infty)=\lim_{k\to\infty}\mathbf{P}(N\ge k)\le\lim_k\rho^{k-1}=0$: the state is visited finitely often, almost surely. Also $\mathbb{E}[N]\le\sum_{k\ge1}\rho^{k-1}=1/(1-\rho) <\infty$.

One line is still missing, because $N$ is conditioned on starting at $i$ while the quantity we want, $\sum_{n\ge0}\mathbf{P}(X_n=i)$, is unconditional. Bridge it by conditioning on whether $i$ is ever reached at all. Let $V$ be the total number of visits to $i$ from an arbitrary start (or an arbitrary initial distribution). If $i$ is never reached, $V=0$; if it is reached, then from the first visit onward the count is distributed exactly as $N$ (Markov property, restarting the chain at that first visit). Hence $V$ is stochastically dominated by $N$, and for every starting state $$\mathbb{E}[V]\le\mathbb{E}[N]\le\frac1{1-\rho}<\infty .$$ Now $\mathbb{E}[V]=\sum_{n\ge0}\mathbf{P}(X_n=i)$ (expected value of a sum of indicators, G2 §2), so that series converges, and a convergent series must have terms going to zero: $\mathbf{P}(X_n=i)\to0$. $\blacksquare$

Interpretation. The geometric argument is the same one behind "an event of fixed positive probability, given infinitely many independent chances, happens eventually" (G2 §3). Transience is precisely a repeated fixed-probability chance to leave for good — so leaving for good is certain, and the long-run picture only ever involves recurrent states.
Practice 2.1. A chain on $\{1,2,3\}$ has $p_{12}=1$; $p_{23}=1$; $p_{31}=0.5$, $p_{33}=0.5$. Classify the states.
Answer

$A(1)$: from 1 go to 2, from 2 to 3, from 3 back to 1 or stay. So $A(1)=\{1,2,3\}$, and every one of those states reaches 1 again ($2\to3\to1$, $3\to1$). No leak, so 1 is recurrent; by the same argument so are 2 and 3, and $\{1,2,3\}$ is a single recurrent class. (Period: the self-loop at 3 gives a cycle of length 1 through 3, and $\gcd$ of anything with 1 is 1, so the class is aperiodic — see §2.3.)

Practice 2.2. True or false: if $p_{ii}>0$ then $i$ is recurrent.
Answer

False. A self-loop only says the chain may linger at $i$; it says nothing about whether it can leave permanently. Counterexample: $p_{11}=0.9$, $p_{12}=0.1$, $p_{22}=1$. Then $2\in A(1)$ but $1\notin A(2)$, so state 1 is transient despite its fat self-loop. (State 2 of Figure 2.5(b) is the lecture's own instance of this.)

2.2 Recurrent classes and the decomposition of a chain

Definition (recurrent class; L17 slide 3). A recurrent class is a collection of recurrent states that communicate with each other and with no other state: for $i$ recurrent, the class is $A(i)$, and one shows $A(i)=A(j)$ for every $j\in A(i)$ (B&T §7.2, p. 350). Equivalently: a recurrent class is a set $R$ of states that is closed (no arc leaves $R$: $p_{ij}=0$ whenever $i\in R$, $j\notin R$) and irreducible (every state of $R$ is accessible from every other).

Why $A(i)=A(j)$ for recurrent $i$ and $j\in A(i)$. Take any $k\in A(j)$. Since $j\in A(i)$, concatenating the path $i\to j$ with the path $j\to k$ gives a path $i\to k$, so $k\in A(i)$: thus $A(j)\subseteq A(i)$. Conversely take $k\in A(i)$. Because $i$ is recurrent and $j\in A(i)$, there is a return path $j\to i$; concatenating it with $i\to k$ gives $j\to k$, so $k\in A(j)$ and $A(i)\subseteq A(j)$. Hence the two sets are equal, and every state of the class has the same accessible set — the class. $\blacksquare$

Theorem (decomposition; B&T §7.2, p. 350, its Figure 7.9). The states of any finite Markov chain split into one or more recurrent classes, plus possibly some transient states. At least one recurrent class always exists. A recurrent state is accessible from all states of its class, but is not accessible from recurrent states of any other class.

Why at least one recurrent class exists (finite chain). Suppose every state were transient. Start anywhere, say $i_1$. Transience gives a state $i_2\in A(i_1)$ with $i_1\notin A(i_2)$; $i_2$ is also transient, so there is $i_3\in A(i_2)$ with $i_2\notin A(i_3)$; and so on. The states $i_1,i_2,i_3,\dots$ are all distinct — if $i_r=i_s$ for $r<s$ then $i_r$ would be accessible from $i_{s-1}$ while by construction it is not — which is impossible in a finite state space. Hence some state is recurrent, and its accessible set is a recurrent class. $\blacksquare$

Interpretation (the shape of every Markov chain). Picture the diagram as a few sealed rooms (the recurrent classes) surrounded by corridors (the transient states). The chain wanders the corridors for a while — a finite while, by §2.1 — then falls into one room and stays there forever, moving inside it forever after. Two separate long-run questions follow, and the course answers them in this order: which room? and how long until I am in one? (absorption, §4), and how do I move inside the room? (steady state, §3). The eight-state diagram on L16 slide 7 is drawn to make exactly this picture: transient states $\{1,2,3,4\}$ in a square, leaking left into the absorbing state $\{5\}$ and right into the class $\{6,7,8\}$.
Example 2.2 (L16 slide 7 — the eight-state diagram, annotated). The slide shows eight states with no probabilities: a square $1,2,3,4$ with arcs $3\to4$, $3\leftrightarrow1$, $4\leftrightarrow2$, $1\leftrightarrow2$, plus $1\to5$ and $2\to6$; a lone state 5 with a self-loop; and a right-hand group $6\leftrightarrow7$, $7\leftrightarrow8$ with self-loops at 6, 7, 8. Classify.
Solution

State 5. Its only arc is the self-loop, so $A(5)=\{5\}$ and trivially every state of $A(5)$ returns to 5. State 5 is recurrent; $\{5\}$ is a recurrent class of one state. A one-state recurrent class is exactly an absorbing state: $p_{55}=1$.

The right-hand group. $A(6)=\{6,7,8\}$: $6\to7\to8$ and back again. No arc leaves the group (the only arc pointing at it, $2\to6$, points in). So $\{6,7,8\}$ is closed and irreducible — a second recurrent class.

The square. $A(1)=\{1,2,3,4,5,6,7,8\}$ because $1\to5$ and $1\to2\to6$. But $5\in A(1)$ and $A(5)=\{5\}\not\ni 1$: a leak. So 1 is transient, and the identical argument (each of 2, 3, 4 reaches 1, hence reaches 5) makes 2, 3, 4 transient too.

Answer. Recurrent classes $\{5\}$ and $\{6,7,8\}$; transient states $1,2,3,4$ — the annotation the slide never writes down. Note that no probability values were used anywhere.

Fig. 2.3 — The two rec18 chains, classified. (a) rec18 P1 with $n=4$ fish: one recurrent (absorbing) state 0, four transient states. (b) rec18 P3: recurrent classes $\{s_1\}$ and $\{s_5\}$, transient $s_0,s_2,s_3,s_4$.
Example 2.3 (rec18 P1(c) — painting fish). There are $n$ fish in a lake, some green and the rest blue. Each day Helen catches exactly one fish, equally likely to be any of the $n$; she paints it blue if it is green, and throws it back. With $X_m=$ the number of green fish after $m$ days, the transition probabilities are (rec18 P1(b), worked in §1) $$p_{ij}=\begin{cases}\dfrac{n-i}{n}, & j=i,\\[4pt] \dfrac{i}{n}, & j=i-1,\\[4pt] 0,&\text{otherwise.} \end{cases}$$ List the transient and the recurrent states.
Solution (official solution + both gaps filled)

The official solution. "State 0 is an absorbing state since there is a positive probability that the system will enter it, and once it does, it will remain there forever. Therefore the state with 0 green fish is the only recurrent state, and all other states are then transient."

Gap 1: why $p_{00}=1$. Put $i=0$ in the formula: $p_{00}=(n-0)/n=1$, and $p_{0,-1}$ does not exist. So state 0 is absorbing — once every fish is blue, no fish can ever be repainted green, which is the modeling fact behind the algebra. Formally $A(0)=\{0\}$, so 0 is recurrent by the definition of §2.1, and $\{0\}$ is a recurrent class.

Gap 2: why 0 is reachable from every $i$. The solution says "there is a positive probability that the system will enter it" without showing it. For $i\ge1$ we have $p_{i,i-1}=i/n>0$, so the single path $i\to i-1\to\cdots\to 1\to 0$ has probability $$\frac{i}{n}\cdot\frac{i-1}{n}\cdots\frac{1}{n}=\frac{i!}{n^{i}}>0,$$ (the product of the one-step probabilities along the path, by the Markov property), hence $0\in A(i)$ for every $i$.

Conclusion. For any $i\ge1$: $0\in A(i)$ but $A(0)=\{0\}$ does not contain $i$ (no arc ever increases the state). That is a leak, so every state $i\ge1$ is transient and state 0 is the unique recurrent state, forming the unique recurrent class $\{0\}$. A graph search on the $n=4$ matrix confirms it (keys fish_classes, fish_transient).

Gap 3 (part (a) never writes the model down). For the record: state space $\{0,1,\dots,n\}$; initial state $X_0=$ the number of green fish at the start; the chain is time-homogeneous because each day's catch is a fresh uniform draw over the $n$ fish, independent of history; and the Markov property holds because tomorrow's green count is determined by today's count $i$ and today's catch alone — the identities of the fish already painted are irrelevant to the count.

Numbers ($n=4$, starting from all-green $X_0=4$; computed in computes/g5_s2.py). $\mathbf{P}(X_m=0)=0$, $0.234375$, $0.780602$, $0.999286$ for $m=1,5,10,30$ — the transient states drain away exactly as the Property of §2.1 predicts.

Gotcha (a tempting wrong shortcut on the fish chain). "Each fish is caught on a given day with probability $1/n$, so it is still green after $m$ days with probability $(1-1/n)^m$; therefore $\mathbf{P}(X_m=0)=\big(1-(1-1/n)^m\big)^{n}$." The first sentence is right, the conclusion is wrong: the events "fish $A$ never caught" and "fish $B$ never caught" are not independent, because exactly one fish is caught per day (catching $A$ uses up the day). For $n=4$, $m=10$ the product formula gives $0.793069$ while the true value from the chain is $0.780602$ (keys fish_absorb_m10_naive_product, fish_absorb_m10_matrix). What does survive is the mean, by linearity of expectation (no independence needed): $\mathbb{E}[X_m\mid X_0=n]=n(1-1/n)^m$; for $n=4,m=10$ both the matrix computation and the formula give $0.2252540588$ (keys fish_Egreen_m10_matrix, fish_Egreen_m10_formula).
Example 2.4 (rec18 P3 — classify the six-state chain). The chain of Fig. 2.3(b) has $p_{01}=p_{03}=p_{05}=1/3$; $p_{11}=1$; $p_{22}=p_{21}=1/2$; $p_{33}=p_{32}=1/4$, $p_{34}=1/2$; $p_{44}=p_{45}=1/2$; $p_{55}=1$. Find the recurrent classes and the transient states, and say what happens to $r_{s_0j}(n)$ as $n\to\infty$.
Solution

Classes. $p_{11}=1$ so $A(s_1)=\{s_1\}$: $s_1$ is absorbing, hence a recurrent class of its own. Likewise $p_{55}=1$ makes $\{s_5\}$ a recurrent class. For the rest: from $s_0$ the first step already reaches $s_1$, $s_3$, $s_5$, and from $s_3$ one reaches $s_2$ and $s_4$, so $A(s_0)=\{s_0,s_1,s_2,s_3,s_4,s_5\}$ — everything; but $s_1\in A(s_0)$ and $A(s_1)=\{s_1\}\not\ni s_0$, a leak, so $s_0$ is transient. $A(s_2)=\{s_1,s_2\}$ with the same leak into $s_1$: transient. $A(s_3)=\{s_1,s_2,s_3,s_4,s_5\}$: transient. $A(s_4)= \{s_4,s_5\}$: transient. Recurrent classes $\{s_1\}$ and $\{s_5\}$; transient $s_0,s_2,s_3,s_4$ (verified by graph search, key p3_classes). Both classes are aperiodic: a self-loop of probability 1 is a cycle of length 1, so $d=\gcd\{1,2,3,\dots\}=1$.

The limit exists but depends on the start. Since the transient states drain away, the chain ends at $s_1$ or at $s_5$, and the only question is which. From $s_3$: the chain lingers on the self-loop, then leaves; the escape is to $s_2$ (prob. $1/4$ per step) or to $s_4$ (prob. $1/2$ per step), so, summing over the number $m\ge0$ of self-loops taken first, $$\mathbf{P}(\text{leaves }s_3\text{ to } s_2)=\sum_{m=0}^{\infty}\Big(\frac14\Big)^{m}\frac14 =\frac{1/4}{1-1/4}=\frac13 ,$$ using the geometric sum $\sum_{m\ge0}x^m=1/(1-x)$ with $x=1/4$ (G2 §3) — this also proves the chain leaves $s_3$ with probability 1, since the same computation with escape probability $1/4+1/2=3/4$ gives $\frac{3/4}{1-1/4}=1$. Once at $s_2$ the chain can only end at $s_1$; once at $s_4$ only at $s_5$. Hence $$\mathbf{P}(\text{end at } s_1\mid X_0=s_3)=\tfrac13,\qquad \mathbf{P}(\text{end at } s_5\mid X_0=s_3)=\tfrac23 .$$ From $s_0$, condition on the first step (total probability, G1 §2): $$\mathbf{P}(\text{end at } s_1\mid X_0=s_0)=\tfrac13\cdot 1+\tfrac13\cdot\tfrac13+\tfrac13\cdot 0 =\tfrac13+\tfrac19=\tfrac49=0.444444,$$ the three terms being the first step to $s_1$ (then certainly $s_1$), to $s_3$ (then $1/3$), and to $s_5$ (then never $s_1$); and $1-4/9=5/9=0.555556$ for $s_5$. Matrix powers agree: $r_{s_0\cdot}(400)=(0,\,0.444444,\,0,\,0,\,0,\,0.555556)$ and $r_{s_3\cdot}(400)=(0,\,0.333333,\,0,\,0,\,0,\,0.666667)$ (keys p3_limit_row_s0, p3_limit_row_s3). Two different starting states, two different limits — the first failure mode of §2.4, in a chain you have already met.

Aside (rec18 P3(b), the classification reading). "Never enters $s_4$" happens iff the first step goes to $s_1$ or $s_5$ (probability $2/3$), or goes to $s_3$ ($1/3$) and then escapes to $s_2$ rather than $s_4$ ($1/3$ by the geometric sum above): $\frac23+\frac13\cdot\frac13=\frac79=0.777778$ (key p3_never_enter_s4) — the official answer, with the gap (why the "given a change of state" conditioning is legitimate) filled by the geometric series.

Practice 2.3. In the fish chain of Fig. 2.3(a), is state 1 accessible from state 0? Is state 0 accessible from state 1? What does that say about state 1?
Answer

No: from state 0 the only arc is the self-loop, so $A(0)=\{0\}$ and $1\notin A(0)$. Yes: $p_{10}=1/n>0$, so $0\in A(1)$. Since $0\in A(1)$ but $1\notin A(0)$, state 1 is transient — the definition applied literally.

Practice 2.4. Can a finite Markov chain have zero recurrent classes? Exactly one? Two disjoint classes each of size one? Give a chain or a reason for each.
Answer

Zero: impossible — the decomposition theorem above proves at least one exists in a finite chain (the argument constructs infinitely many distinct states otherwise). Exactly one: yes — the fish chain, whose only class is $\{0\}$; more generally any chain whose recurrent states all communicate. Two singleton classes: yes — rec18 P3, with $\{s_1\}$ and $\{s_5\}$ both absorbing. (Infinite chains can have no recurrent state: the walk $p_{i,i+1}=1$ on $\{0,1,2,\dots\}$ escapes to infinity and every state is transient — B&T §7.2 discusses this in its end-of-chapter problems.)

2.3 Periodicity

Recurrence answers "does the chain keep coming back?". Periodicity answers "does it come back on a schedule?" — and a schedule is exactly what prevents $r_{ij}(n)$ from settling down.

Definition (periodicity, grouping form; L17 slide 4). The states of a recurrent class $R$ are periodic if $R$ can be partitioned into $d>1$ groups $S_1,\dots,S_d$ such that all transitions from one group lead to the next group: $$i\in S_k,\ p_{ij}>0 \;\Longrightarrow\; j\in S_{k+1}\quad(\text{and } j\in S_1 \text{ if } k=d).$$ The largest such $d$ is the period. If no such grouping exists with $d>1$, the class is aperiodic ($d=1$).
Definition (periodicity, gcd form; B&T §7.2, p. 351). The period of a state $i$ is $$d=\gcd\{\,n\ge 1:\ r_{ii}(n)>0\,\},$$ the greatest common divisor of the lengths of all cycles through $i$. All states of a recurrent class share the same $d$, and the two definitions agree.

Why the two definitions agree (the argument L17 makes verbally). Suppose the grouping exists with $d$ groups. Starting in $S_1$, after $n$ steps the chain is in $S_{(n \bmod d)+1}$ — a one-line induction, since each step advances the group index by exactly one. To be back at $i\in S_1$ we need $n\bmod d=0$, so every return time is a multiple of $d$ and hence $d$ divides the gcd. Conversely, given the gcd $d$, define the group of a state $j$ by the residue mod $d$ of the length of any path $i\to j$: this is well defined (two paths $i\to j$ of lengths $\ell_1,\ell_2$ can each be completed to a cycle through $i$ by the same return path of length $\ell$, giving cycles of lengths $\ell_1+\ell$ and $\ell_2+\ell$, both multiples of $d$, so $\ell_1\equiv\ell_2 \bmod d$), and by construction every transition advances the residue by one. $\blacksquare$

Fig. 2.4 — (a) The grouping definition of periodicity, $d=3$ (L17 slide 4; B&T §7.2, its Figure 7.10). (b) The lecture's state-level example: two directed cycles of lengths 6 and 4 sharing one state; $\gcd(6,4)=2$, so the period is 2 and the two groups are the even/odd-distance states.
Example 2.5 (L17 slide 4 — why the two-cycle chain has period 2; the derivation the slide omits). Fig. 2.4(b) shows nine states forming two directed cycles that share state 0: a left cycle $0\to1\to2\to3\to4\to5\to0$ of length 6 and a right cycle $0\to6\to7\to8\to0$ of length 4. Find the period.
Solution

Step 1 — the chain is a single recurrent class. Every state lies on a cycle through 0, so every state reaches 0 and 0 reaches every state; hence all nine states communicate and no arc leaves the set. One recurrent class (key cyc_single_class).

Step 2 — the return times to state 0. A return to 0 consists of choosing, on each visit, the left loop (6 steps) or the right loop (4 steps). So the possible return times are exactly $$n=6a+4b,\qquad a,b\ge 0,\ a+b\ge 1: \quad n\in\{4,6,8,10,12,14,\dots\},$$ i.e. every even number $\ge 4$ (matrix powers confirm: $r_{00}(n)>0$ precisely for $n=4,6,8,10,12,14$ in the range $n\le14$, key cyc_return_times_n_le_14).

Step 3 — take the gcd. $d=\gcd\{4,6,8,\dots\}=\gcd(6,4)=2$. Since $d=2>1$, the class is periodic with period 2 (key cyc_period_state0).

Step 4 — exhibit the two groups. Color each state by the parity of its distance from 0 along the arrows: $S_1=\{0,2,4,7\}$ (even) and $S_2=\{1,3,5,6,8\}$ (odd) — the blue/orange coloring of Fig. 2.4(b) (keys cyc_group_even, cyc_group_odd). Every arrow in the picture goes from one color to the other, which is the grouping definition verified by eye. The grouping exists only because the two cycle lengths share the factor 2: replace the right cycle by one of length 3 and the return times become $\{3,6,9,\dots\}\cup\{6,12,\dots\}$ combinations $6a+3b$ with $\gcd=3$ (period 3), while replacing the left cycle by one of length 3 alongside the length-4 cycle would give $\gcd(3,4)=1$ and an aperiodic chain.

Step 5 — the consequence. $r_{00}(n)=0$ for every odd $n$, forever: no limit. Numerically $r_{00}(120)=0.4$ but $r_{00}(121)=0$ (keys cyc_r00_n120, cyc_r00_n121). The value $0.4$ is not an accident: the long-run fraction of time spent at state 0 is $\pi_0=1/\mathbb{E}[\text{return time}]=1/(0.5\cdot 6+0.5\cdot 4)=1/5=0.2$, and the chain can only be at 0 on even steps, so on those steps it is there with probability $d\pi_0=2\times0.2=0.4$.

Recipe (spotting periodicity fast).
  1. Any self-loop in the class $\Rightarrow$ aperiodic. A self-loop is a cycle of length 1 and $\gcd(1,\text{anything})=1$. This one test settles most exam chains instantly.
  2. Two cycles of coprime lengths $\Rightarrow$ aperiodic (e.g. lengths 2 and 3).
  3. Try to 2-color / $d$-color the diagram. If you can group the states so that every arc goes from group $k$ to group $k+1$, the class is periodic with that $d$; if any arc stays inside a group or skips one, no such grouping exists.
  4. Positive-matrix test (B&T §7.2, p. 351). The class is aperiodic iff there exists $n\ge1$ and a state $i$ from which all states of the class are reachable in exactly $n$ steps; equivalently, $r_{ij}(n)>0$ for all $i,j$ in the class for all large enough $n$. It is this second, all-pairs form that the compute checks: the smallest $n$ making every entry $r_{ij}(n)$ positive is 2 for both classes of Fig. 2.2 (keys warmup_class1_first_all_pos_n, warmup_class2_first_all_pos_n). The single-state form is satisfied even earlier — state 3 reaches 3, 4 and 5 in exactly one step, and state 6 reaches 6 and 7 in one step, so there $n=1$ already suffices. For the periodic chains of Figs. 2.4(b) and 2.5(a) no such $n$ exists at all, in either form (keys cyc_first_all_pos_n, per3_first_all_pos_n, both None).
Gotcha. Periodicity is a property of a recurrent class, not of the whole chain and not of transient states. Do not ask "is this chain periodic?" until you have found the classes: a chain can have one periodic and one aperiodic class at the same time, and then the convergence theorem simply does not apply. Also: "period $d$" does not mean the chain returns every $d$ steps — in Example 2.5 the return times are $4,6,8,\dots$, never 2 — it means all return times are multiples of $d$ and $d$ is the largest such number.
Practice 2.5. A recurrent class has cycles of lengths 4, 6 and 9 through some state $i$. What is the period?
Answer

$d=\gcd(4,6,9)$. Compute: $\gcd(4,6)=2$, $\gcd(2,9)=1$. So $d=1$ — aperiodic, even though no self-loop is present. One odd cycle among even ones is enough to destroy periodicity.

Practice 2.6. The two-state chain with $p_{12}=p_{21}=1$ (and no self-loops) is the smallest periodic chain. Write $r_{11}(n)$ and $r_{12}(n)$ for all $n$, and give the groups.
Answer

From 1 the chain is at 1 after an even number of steps and at 2 after an odd number, with probability 1 each time (there is no randomness at all): $r_{11}(n)=1$ for $n$ even, $0$ for $n$ odd; $r_{12}(n)=0$ for $n$ even, $1$ for $n$ odd. Return times to 1: $\{2,4,6,\dots\}$, gcd $=2=d$. Groups $S_1=\{1\}$, $S_2=\{2\}$. Neither $r_{11}(n)$ nor $r_{12}(n)$ has a limit. This is the $\varepsilon=0$ end of the widget in §2.4.

2.4 The steady-state convergence theorem, and the two ways it fails

We can now state the theorem the classification was built for.

Steady-State Convergence Theorem (L17 slide 5; B&T §7.3, p. 352). Consider a Markov chain with a single recurrent class which is aperiodic. Then for every state $j$ the $n$-step probabilities converge, $$\lim_{n\to\infty} r_{ij}(n)=\pi_j \qquad\text{for every starting state } i,$$ to a limit $\pi_j$ that does not depend on $i$. The $\pi_j$ are the steady-state probabilities, $\pi_j\approx\mathbf{P}(X_n=j)$ for large $n$, and they satisfy the balance equations together with normalization: $$\pi_j=\sum_k \pi_k p_{kj}\ \ \text{for all } j,\qquad \sum_j \pi_j=1 .$$

Where the balance equations come from (L17 slide 5, with the limit step made explicit). Start from the Chapman–Kolmogorov recursion, valid for every $n$ and every $i$: $$r_{ij}(n)=\sum_k r_{ik}(n-1)\,p_{kj}.$$ Let $n\to\infty$. On the left, $r_{ij}(n)\to\pi_j$ by the theorem. On the right, each term $r_{ik}(n-1)\to\pi_k$, and for a finite state space the sum has finitely many terms, so the limit passes through the sum (a finite sum of convergent sequences converges to the sum of the limits — no interchange theorem needed). Hence $\pi_j=\sum_k \pi_k p_{kj}$. Similarly, summing $\sum_j r_{ij}(n)=1$ over the finitely many $j$ and taking limits gives $\sum_j\pi_j=1$. $\blacksquare$

Gotcha (why normalization is not optional — the gap L17 slide 5 leaves). The balance equations alone cannot determine $\pi$: they are homogeneous, so if $\pi$ solves them then so does $c\pi$ for any constant $c$, and $\pi=0$ always solves them. In matrix form $\pi(P-I)=0$, and $P-I$ is singular because every row of $P$ sums to 1 (so $(P-I)\mathbf{1}=0$). One of the $m$ balance equations is therefore redundant; you throw it away and put $\sum_j\pi_j=1$ in its place. That is exactly how computes/g5_s2.py solves for every $\pi$ on this page. Conversely, the balance equations having a solution proves nothing about convergence: see Example 2.6.
Fig. 2.5 — The two failure modes, drawn on L16 slide 6's own chains. (a) One recurrent class but period $d=2$. (b) Two recurrent classes, $\{1\}$ and $\{3,4\}$, with 2 transient.
Fig. 2.6 — The same two chains, numerically. (a) $r_{i2}(n)$ never settles; it merely alternates about its time-average $\pi_2=1/2$. (b) $r_{i1}(n)$ converges for each start, to three different values. Computed in computes/g5_s2_figs.py from matrix powers.
Example 2.6 (L16 slide 6, first fill-in — periodicity kills convergence). The three-state chain of Fig. 2.5(a) has $p_{12}=1$, $p_{21}=p_{23}=0.5$, $p_{32}=1$. The slide asks for $r_{22}(n)$ for $n$ odd and for $n$ even, and leaves both blanks empty. Fill them in.
Solution

Structure first. All three states communicate ($1\to2\to3$, $3\to2\to1$) and no arc leaves the set, so there is a single recurrent class $\{1,2,3\}$, no transient states (key per3_classes). Cycles through 2: $2\to1\to2$ and $2\to3\to2$, both of length 2; every cycle is a concatenation of these, so all return times are even and $d=\gcd\{2,4,6,\dots\}=2$ (key per3_period). Groups: $S_1=\{2\}$, $S_2=\{1,3\}$ — every arc goes between them.

The fill-ins. Starting at 2, after one step the chain is at 1 or 3 (never 2); after two steps it is back at 2 with probability 1, since from 1 the only arc is $1\to2$ and from 3 the only arc is $3\to2$. By induction, the chain is at 2 at every even time and away from 2 at every odd time: $$\boxed{r_{22}(n)=0 \text{ for } n \text{ odd},\qquad r_{22}(n)=1 \text{ for } n \text{ even.}}$$ Matrix powers for $n=1,\dots,8$: $0,1,0,1,0,1,0,1$ (key per3_r22_n1to8).

Starting elsewhere. From 1: $r_{12}(n)=1$ for $n$ odd and $0$ for $n$ even — the opposite phase. And $r_{11}(n)=0$ for odd $n$, $=0.5$ for even $n\ge2$ (key per3_r11_n1to8), because from 1 the chain is at 2 after one step and then splits evenly between 1 and 3. So $r_{ij}(n)$ has no limit for any $i,j$ here.

But the balance equations still have a solution. Solving $\pi_1=0.5\pi_2$, $\pi_2=\pi_1+\pi_3$, $\pi_3=0.5\pi_2$ with $\pi_1+\pi_2+\pi_3=1$ gives $\pi=(0.25,0.5,0.25)$ (key per3_balance_solution). It is not a limit of $r_{ij}(n)$ — nothing converges to it. What it is, is the long-run fraction of time spent in each state: averaging the first $N=20{,}000$ matrix powers gives row 1 of the average equal to $(0.25,0.5,0.25)$ to six decimals (key per3_cesaro_row1). This is the general rule for periodic chains: time averages converge even when the probabilities themselves oscillate.

Example 2.7 (L16 slide 6, second fill-in — two classes make the limit remember the start). The four-state chain of Fig. 2.5(b): state 1 absorbing; state 2 with $p_{22}=0.4$, $p_{21}=0.3$, $p_{23}=0.3$; states 3 and 4 with $p_{33}=p_{34}=p_{43}=p_{44}=0.5$. The slide asks for $r_{11}(n)$, $r_{31}(n)$, $r_{21}(n)$ and leaves all three blank.
Solution

Structure. $A(1)=\{1\}$, so $\{1\}$ is a recurrent class (absorbing). $A(3)=A(4)=\{3,4\}$, closed and communicating, so $\{3,4\}$ is a second recurrent class — aperiodic, because of the self-loops. $A(2)=\{1,2,3,4\}$ with two leaks, so 2 is the only transient state (key two_classes). Two recurrent classes: the theorem does not apply.

$r_{11}(n)$. State 1 is absorbing, $p_{11}=1$, so starting there the chain never moves: $$\boxed{r_{11}(n)=1\quad\text{for all } n\ge 0.}$$

$r_{31}(n)$. From 3 the chain can only visit 3 and 4 — state 1 is not accessible from 3 at all (no arc leaves $\{3,4\}$). So $$\boxed{r_{31}(n)=0\quad\text{for all } n\ge 0.}$$

$r_{21}(n)$. From 2 the chain stays at 2 for a geometric number of steps and then leaves, going to 1 or to 3 with equal probability $0.3$. Two derivations.

By first-step conditioning, exactly. Let $a_n=r_{21}(n)$. Conditioning on the first transition (total probability, and the Markov property to restart the chain): $$a_n=0.3\cdot r_{11}(n-1)+0.4\cdot a_{n-1}+0.3\cdot r_{31}(n-1)=0.3+0.4\,a_{n-1},$$ using $r_{11}=1$ and $r_{31}=0$ from above, with $a_0=0$. Solve the linear recursion: the fixed point is $a^*=0.3/(1-0.4)=0.5$, and writing $a_n-0.5=0.4(a_{n-1}-0.5)$ gives $a_n-0.5=(0.4)^n(a_0-0.5)=-0.5(0.4)^n$, i.e. $$\boxed{r_{21}(n)=\tfrac12\big(1-(0.4)^n\big)\ \longrightarrow\ \tfrac12 .}$$ Check at $n=7$: the formula gives $0.4991808000$ and the matrix power gives $0.4991808000$ (keys two_r21_n7_formula, two_r21_n7_matrix).

By symmetry, instantly. The chain leaves state 2 eventually with probability 1, and at the moment it leaves it is equally likely to go to 1 or to 3 because $p_{21}=p_{23}=0.3$; the self-loop is irrelevant to which exit is taken. So the absorption probability into $\{1\}$ is $1/2$ — the limit above.

The point. Three starting states, three different limits: $1$, $0$, and $1/2$ (key two_r21_limit). The limits exist here — each class is aperiodic — but they depend on $i$, so there is no single steady-state vector $\pi$, and asking for "the" $\pi_1$ is meaningless. Note also $r_{23}(n)+r_{24}(n)\to 1/2$ split as $(0.25,0.25)$ by the symmetry of the class $\{3,4\}$ (keys two_r23_n30): the surviving half of the probability distributes itself according to the steady state of the class it landed in, exactly as in the warm-up chain of §2.1.

Interpretation (why exactly these two hypotheses). The theorem asks for one recurrent class and no periodicity, and each hypothesis kills one specific pathology.
  • Several classes $\Rightarrow$ the chain remembers its start forever, because the class it falls into is decided by where it began (Fig. 2.5(b), rec18 P3, the warm-up chain). The limit may exist, but it is not a single $\pi$.
  • Periodicity $\Rightarrow$ the chain remembers the clock forever: the group it is in at time $n$ is determined by $n \bmod d$ and the starting group, so $r_{ij}(n)$ oscillates (Fig. 2.5(a)). Here even the time-average is fine; only the instantaneous distribution misbehaves.
Neither restriction is as severe as it sounds. Multiple classes reduce to the single-class case, since once the chain enters a class it stays there and behaves like the single-class chain on that class — which is precisely why the warm-up limit factored as (absorption probability) $\times$ (that class's $\pi$). And periodicity is a knife's-edge condition: adding the tiniest self-loop anywhere in the class makes it aperiodic, as the widget below shows.

Widget: how a sliver of self-loop turns oscillation into convergence

Take the smallest periodic chain, $1\to2\to1$ deterministically, and bleed a little probability $\varepsilon$ into a self-loop at state 1: $$P=\begin{pmatrix} \varepsilon & 1-\varepsilon\\ 1 & 0\end{pmatrix},\qquad 0\le\varepsilon<1 .$$ At $\varepsilon=0$ this is Practice 2.6, period 2. For any $\varepsilon>0$ the self-loop is a cycle of length 1, so the class $\{1,2\}$ is aperiodic and the theorem applies with $$\pi_1=\frac{1}{2-\varepsilon},\qquad \pi_2=\frac{1-\varepsilon}{2-\varepsilon}$$ (from $\pi_1=\varepsilon\pi_1+\pi_2$ and $\pi_1+\pi_2=1$: substituting $\pi_2=1-\pi_1$ gives $\pi_1=\varepsilon\pi_1+1-\pi_1$, so $\pi_1(2-\varepsilon)=1$). The exact transient behaviour is $$r_{11}(n)=\pi_1+(1-\pi_1)(\varepsilon-1)^n,$$ verified against matrix powers at $n=6$ for $\varepsilon=0,0.05,0.2,0.5$ in computes/g5_s2.py (keys w_eps*_r11_n6_closed vs w_eps*_r11_n6_matrix). The second eigenvalue is $\varepsilon-1$, whose magnitude is $1-\varepsilon$: it equals 1 exactly at $\varepsilon=0$ (undamped oscillation) and shrinks as $\varepsilon$ grows — the number of steps needed for $|r_{11}(n)-\pi_1|<0.001$ is 121, 28, 9 for $\varepsilon=0.05,0.2,0.5$ (keys w_eps*_n_to_1e-3).

Practice 2.7. A chain has recurrent classes $\{1,2\}$ (aperiodic) and $\{5,6\}$ (period 2), plus transient states 3, 4. Does $\lim_n r_{31}(n)$ exist? Does $\lim_n r_{35}(n)$?
Answer

$\lim_n r_{31}(n)$ exists: conditional on ending in the aperiodic class $\{1,2\}$ — an event of some probability $\alpha$ decided by the absorption analysis of §4 — the chain's distribution inside that class converges to its own $\pi$, so $r_{31}(n)\to\alpha\,\pi_1^{\{1,2\}}$. $\lim_n r_{35}(n)$ does not exist in general: inside a periodic class the probability keeps oscillating, so $r_{35}(n)$ oscillates too (damped only by the randomness in the entry time into the class — and if the chain enters $\{5,6\}$ at both even and odd times the oscillation can be washed out, which is why "in general"). The safe statement is that the time-average always converges.

Practice 2.8. Someone hands you the chain $p_{11}=0.5$, $p_{12}=0.5$, $p_{21}=0.2$, $p_{22}=0.8$ (L17 slide 7) and asks whether the balance equations may be used. Answer before solving anything.

§2 cheatsheet — classification of states
  • Accessible: $j\in A(i)$ iff $r_{ij}(n)>0$ for some $n\ge0$ iff there is a directed path $i\to j$. Always $i\in A(i)$; accessibility is one-way.
  • Recurrent: $i\in A(j)$ for every $j\in A(i)$ ("from wherever you can go, there is a way back"). Transient: otherwise — some $j\in A(i)$ has no road back. Depends only on which $p_{ij}$ are positive, never on their values (L17 slide 3; B&T §7.2).
  • Recurrent class: $A(i)$ for recurrent $i$; closed (no arc out) and irreducible (all states communicate). Absorbing state = recurrent class of size one, $p_{ii}=1$.
  • Decomposition: every finite chain = one or more recurrent classes + possibly transient states; at least one class always exists.
  • Transient states die out: $\mathbf{P}(X_n=i)\to0$, visited finitely often (geometric escape argument).
  • Period: $d=\gcd\{n\ge1: r_{ii}(n)>0\}$ = gcd of cycle lengths through $i$; equivalently the class splits into $d$ groups with all transitions $S_k\to S_{k+1}$. One self-loop in the class $\Rightarrow d=1$. Aperiodic $\iff$ $r_{ij}(n)>0$ for all $i,j$ in the class for all large $n$.
  • Convergence theorem: single recurrent class and aperiodic $\Rightarrow$ $r_{ij}(n)\to\pi_j$ for every $i$, with $\pi_j=\sum_k\pi_kp_{kj}$ and $\sum_j\pi_j=1$ (§3 solves these).
  • Failure 1 — several classes: limits exist but depend on the start ($r_{11}=1$, $r_{31}=0$, $r_{21}\to1/2$ in Fig. 2.5(b); $4/9$ vs $1/3$ in rec18 P3).
  • Failure 2 — periodicity: $r_{ij}(n)$ oscillates and has no limit ($r_{22}(n)=1,0,1,0,\dots$ in Fig. 2.5(a)); the balance equations may still have a solution, but it is a long-run fraction of time, not a limit of $r_{ij}(n)$.
  • Practical order of work: classes first, period second, equations third. Never the other way round.
