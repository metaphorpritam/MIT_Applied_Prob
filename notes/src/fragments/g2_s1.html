§1   Random variables and PMFs

Sources: L05 slides 2–6 (raster p01–p02) · B&T (Bertsekas–Tsitsiklis, as in §0) §2.1–2.2 (pp. 72–79), B&T Figure 2.2 (p. 76) — throughout this note a bare § is a section of the note, a § prefixed by B&T is a section of the textbook · numbers recomputed in computes/g2_s1.py

Group G1 built probability models out of sets: a sample space $\Omega$, events $A \subseteq \Omega$, and a probability law $\mathbf{P}$ obeying the three axioms. That machinery is complete but clumsy for quantitative questions. If you want to know how long a queue is, how many packets were corrupted, or how many tosses it took to see a head, you do not want a set — you want a number. A random variable is exactly the device that attaches a number to each outcome, and the probability mass function is the object that carries all the probabilistic information about that number.

This section does four things. It defines a random variable as a function on the sample space and pins down the notation the rest of the course uses. It defines the PMF $p_X(x) = \mathbf{P}(X=x)$, proves its two defining properties from the G1 axioms, and turns the definition into a mechanical recipe — applied in full to the tetrahedral-die example that L05 slide 4 leaves blank. It then derives the four named discrete PMFs of L05 (Bernoulli, discrete uniform, binomial, geometric) from their experiments, filling in every step the slides compress, including the geometric-series normalization check. It closes with a decision guide, a comparison figure, and an interactive PMF explorer. Expectation and variance — the numerical summaries of a PMF — are §2 and §3.

1.1 What a random variable is

The definition is disarmingly simple, and the simplicity is the point: a random variable is not a variable and it is not random. It is a fixed, deterministic function. All the randomness lives where it always lived, in which outcome $\omega$ the experiment produces.

Definition (random variable; L05 slide 2, B&T §2.1). Given a probabilistic model with sample space $\Omega$, a random variable is an assignment of a value (a number) to every possible outcome — mathematically, a function $$X : \Omega \to \mathbb{R}, \qquad \omega \mapsto X(\omega).$$ Here $\omega$ is an outcome (one element of $\Omega$), and $X(\omega)$ is the real number that $X$ assigns to it. The random variable is called discrete if its range — the set of values $\{X(\omega) : \omega \in \Omega\}$ it can actually take — is finite or countably infinite; otherwise it is not discrete (B&T §2.1, p. 73). This section, and all of L05–L07, treats discrete random variables only.

Notation (L05 slide 2). Upper case for the random variable, lower case for a numerical value it might take: $X$ is the function, $x$ is a number. "$X = x$" is shorthand for the event $\{\omega \in \Omega : X(\omega) = x\}$ — the set of outcomes that $X$ maps to $x$. Keeping the two cases straight is not pedantry; every formula below depends on it.

Interpretation — where the randomness is. Read $X$ as a measuring instrument permanently bolted to the experiment. Before the experiment runs, the instrument's dial has no reading, but the wiring is completely determined: if outcome $\omega$ occurs, the dial will read $X(\omega)$, no exceptions. Run the experiment, an outcome $\omega$ is drawn according to $\mathbf{P}$, and the instrument reads out the corresponding number. So "$X$ is random" is loose talk for "the input to the deterministic function $X$ is random". This is why every probability question about $X$ can be pushed back to a probability question about a set of outcomes, which is a question G1 already knows how to answer.

Two consequences of "$X$ is a function on $\Omega$" get used constantly.

Property (several random variables on one sample space; L05 slide 2). Nothing stops you from defining many functions on the same $\Omega$. Each is its own random variable, and they all describe the same experiment from different angles.
Example 1.1 (L05 slide 4; B&T §2.1) — three random variables on one 16-outcome space. Roll a fair tetrahedral (4-sided) die twice, independently. From G1 the model is $$\Omega = \{1,2,3,4\}^2 = \{(f,s) : f,s \in \{1,2,3,4\}\}, \qquad |\Omega| = 4 \times 4 = 16,$$ where the outcome $(f,s)$ records the first roll $f$ and the second roll $s$; by the discrete uniform law each of the $16$ outcomes has probability $1/16$. Four different functions on this one $\Omega$:
  • $F(f,s) = f$ — the outcome of the first throw. Range $\{1,2,3,4\}$.
  • $S(f,s) = s$ — the outcome of the second throw. Range $\{1,2,3,4\}$.
  • $X(f,s) = \min(f,s)$ — the smaller of the two rolls. Range $\{1,2,3,4\}$.
  • $T(f,s) = f + s$ — the total. Range $\{2,3,\ldots,8\}$.
$F$ and $S$ are random variables that happen to be the coordinates of the outcome; $X$ and $T$ are built from them. Note $X = \min(F,S)$ and $T = F + S$ — a function of random variables is again a random variable, because a composition of functions on $\Omega$ is a function on $\Omega$. This example is L05 slide 4's setup, and §1.2 computes the PMF of $X$.
Property (a function of a random variable is a random variable; L05 slide 7 preview, B&T §2.1). If $X : \Omega \to \mathbb{R}$ is a random variable and $g : \mathbb{R} \to \mathbb{R}$ is any function, then $Y = g(X)$, meaning $Y(\omega) = g(X(\omega))$, is again a random variable on the same $\Omega$. If $X$ is discrete so is $Y$, because the range of $Y$ is the image under $g$ of the range of $X$, and the image of a finite or countable set is finite or countable.
Gotcha — "discrete" is about the values, not about $\Omega$. A random variable is discrete when its range is finite or countable; the sample space underneath may be uncountable. Pick a point $a$ uniformly from $[-1,1]$ (an uncountable $\Omega$, G1 §1.4). Then $X(a) = a^2$ is not discrete — it takes every value in $[0,1]$. But on the very same $\Omega$, $$\operatorname{sgn}(a) = \begin{cases} 1, & a > 0,\\ 0, & a = 0,\\ -1, & a < 0\end{cases}$$ is discrete: its range is the three-element set $\{-1,0,1\}$ (B&T §2.1, p. 73). Discreteness is a property of the function's output set, and two random variables on one $\Omega$ can differ in it.
Gotcha — $X$ versus $x$ versus $X(\omega)$. Three different objects wear similar clothes. $X$ is a function; $X(\omega)$ is the number it returns on outcome $\omega$; $x$ is a candidate value you supply. Writing "$\mathbf{P}(X)$" is meaningless — $\mathbf{P}$ eats events, and $X$ is not an event. Writing "$p_X(X)$" is almost always a slip for $p_X(x)$. The only legal probability statements about $X$ are about events built from it: $\{X = x\}$, $\{X \le x\}$, $\{X \in S\}$.

1.2 The probability mass function

A random variable by itself is just a labelling of outcomes. What makes it useful is that the probability law on $\Omega$ pushes forward to a probability law on the numbers.

Definition (PMF; L05 slide 3, B&T §2.2 p. 74). The probability mass function (PMF, also called the "probability law" or "probability distribution") of a discrete random variable $X$ is the function $p_X$ defined for every real number $x$ by $$p_X(x) \;=\; \mathbf{P}(X = x) \;=\; \mathbf{P}\big(\{\omega \in \Omega \ \text{s.t.} \ X(\omega) = x\}\big).$$ In words: $p_X(x)$ is the probability of the event consisting of all outcomes that $X$ sends to $x$. The subscript $X$ names the random variable; the argument $x$ is the value being asked about. For a value $x$ outside the range of $X$ the defining set is empty, so $p_X(x) = 0$.
Property (the two defining properties of a PMF; L05 slide 3). $$p_X(x) \;\ge\; 0 \quad \text{for every } x, \qquad\qquad \sum_x p_X(x) \;=\; 1,$$ the sum running over all values $x$ in the range of $X$. More generally, for any set $S$ of real numbers, $$\mathbf{P}(X \in S) \;=\; \sum_{x \in S} p_X(x). \tag{\text{B\&T }§2.2,\ \text{p. }75}$$
Proof — both properties, from the G1 axioms

Nonnegativity. $p_X(x)$ is by definition $\mathbf{P}(A_x)$ for the event $A_x = \{\omega : X(\omega) = x\}$. Axiom 1 (nonnegativity, G1 §1.2) says every event has probability $\ge 0$, so $p_X(x) \ge 0$. Nothing else is needed.

Normalization. Let $x_1, x_2, \ldots$ be the (finite or countable) list of values in the range of $X$, and put $A_i = \{\omega : X(\omega) = x_i\}$.

Step 1 — the $A_i$ are pairwise disjoint. Suppose $\omega \in A_i \cap A_j$ with $i \neq j$. Then $X(\omega) = x_i$ and $X(\omega) = x_j$, so $x_i = x_j$ — impossible, since the $x_i$ are distinct values. Hence $A_i \cap A_j = \varnothing$ for $i \neq j$. (This step is exactly where "$X$ is a function" is used: a function returns one value per input.)

Step 2 — the $A_i$ cover $\Omega$. Take any $\omega \in \Omega$. The number $X(\omega)$ lies in the range of $X$ by definition of the range, so $X(\omega) = x_i$ for some $i$, i.e. $\omega \in A_i$. Hence $\bigcup_i A_i = \Omega$.

Step 3 — add. Steps 1 and 2 say $\{A_i\}$ is a partition of $\Omega$. By countable additivity (G1 §1.5 — finite additivity suffices when the range is finite), $$\sum_i \mathbf{P}(A_i) \;=\; \mathbf{P}\Big(\bigcup_i A_i\Big) \;=\; \mathbf{P}(\Omega) \;=\; 1,$$ the last equality by Axiom 2 (normalization). Since $\mathbf{P}(A_i) = p_X(x_i)$ by the definition of the PMF, this reads $\sum_x p_X(x) = 1$.

The $\mathbf{P}(X \in S)$ formula. The event $\{X \in S\}$ is the union $\bigcup_{x \in S} A_x$ over the values $x \in S$ that lie in the range (values outside the range contribute $\varnothing$). These sets are pairwise disjoint by Step 1, so additivity gives $\mathbf{P}(X \in S) = \sum_{x \in S} \mathbf{P}(A_x) = \sum_{x \in S} p_X(x)$. $\blacksquare$

Interpretation — the PMF is a redistribution of one unit of mass. Think of $\mathbf{P}$ as one kilogram of probability spread over $\Omega$. The random variable $X$ pushes each outcome onto a point of the real line, and $p_X(x)$ is how much mass lands at the point $x$. The proof above says exactly that: the pile at $x$ is the set of outcomes shipped to $x$; no outcome is shipped to two places (disjointness); no outcome is left behind (covering); so the piles still weigh one kilogram in total. Two very different experiments can produce the same PMF — the PMF forgets $\Omega$ and keeps only the weights. That forgetting is what makes a handful of named PMFs enough to describe thousands of experiments.

The definition converts into a procedure with no thinking required. The lecture states it as three bullets; B&T states it as the two-step box of B&T Figure 2.2.

Recipe — computing a PMF $p_X(x)$ (L05 slide 4; B&T §2.2 p. 75, Figure 2.2).
  1. Fix the model. Write down $\Omega$ and the probability of each outcome (or of the relevant groups of outcomes). Write down $X$ as an explicit rule $\omega \mapsto X(\omega)$.
  2. Find the range. List the values $x$ that $X$ can actually take. These are the only $x$ with $p_X(x) > 0$; everything else gets $0$ automatically.
  3. For each such $x$: collect all the outcomes $\omega$ with $X(\omega) = x$.
  4. Add their probabilities. The sum is $p_X(x)$. (In an equally likely model this is just count the outcomes and divide by $|\Omega|$.)
  5. Repeat for every $x$ in the range.
  6. Check. Verify $\sum_x p_X(x) = 1$. In a counting model the counts must add to $|\Omega|$. This catches the two commonest errors — a missed outcome and an outcome counted twice — at zero cost.
Example 1.2 (L05 slide 4, the blank filled in) — $X = \min(F,S)$ for two rolls of a fair tetrahedral die.

Statement (as printed on the slide). Two independent rolls of a fair tetrahedral die. $F$ is the outcome of the first throw, $S$ the outcome of the second, and $X = \min(F,S)$. Compute $p_X(2)$. The slide leaves the right-hand side blank. We compute $p_X(2)$ and then the whole PMF.

Step 1 — the model. As in Example 1.1, $\Omega = \{1,2,3,4\}^2$ with $|\Omega| = 16$ outcomes, each of probability $\mathbf{P}(\{(f,s)\}) = 1/16$. (Fairness makes the four faces equally likely; independence of the two rolls makes each pair have probability $\tfrac14 \cdot \tfrac14 = \tfrac1{16}$, by the multiplication rule of G1.) The random variable is $X(f,s) = \min(f,s)$.

Step 2 — the range. The minimum of two numbers from $\{1,2,3,4\}$ is again in $\{1,2,3,4\}$, and each of those four values does occur (e.g. $\min(k,k) = k$). So the range is $\{1,2,3,4\}$.

Step 3 — collect the outcomes with $X = 2$. We need $\min(f,s) = 2$: the smaller of the two rolls is $2$. That means both rolls are $\ge 2$ and at least one equals $2$. Listing them systematically — first the ones with $f = 2$, then the extra ones with $s = 2$ and $f > 2$: $$\{X = 2\} \;=\; \{(2,2),\,(2,3),\,(2,4),\,(3,2),\,(4,2)\},$$ which has $5$ outcomes. (Sanity check on the list: $(2,1)$ is excluded because $\min(2,1)=1$; $(3,3)$ is excluded because $\min = 3$.) These are the shaded cells of Fig. 1.1.

Step 4 — add their probabilities. The five outcomes are distinct, hence disjoint as singleton events, so additivity gives $$p_X(2) \;=\; \mathbf{P}(X = 2) \;=\; \underbrace{\tfrac1{16} + \tfrac1{16} + \tfrac1{16} + \tfrac1{16} + \tfrac1{16}}_{5 \text{ terms}} \;=\; \frac{5}{16} \;=\; 0.3125 .$$

Step 5 — repeat for the other values. Same procedure:

  • $\{X = 1\}$: at least one roll equals $1$ (then the min is certainly $1$). Outcomes: the four with $f=1$, plus the three with $s = 1$ and $f \neq 1$ — that is $4 + 3 = 7$ outcomes, so $p_X(1) = 7/16 = 0.4375$.
  • $\{X = 3\}$: both rolls $\ge 3$, at least one equal to $3$: $(3,3),(3,4),(4,3)$ — $3$ outcomes, $p_X(3) = 3/16 = 0.1875$.
  • $\{X = 4\}$: both rolls $\ge 4$, i.e. both equal $4$: $(4,4)$ only — $1$ outcome, $p_X(4) = 1/16 = 0.0625$.

Step 6 — the check. Counts: $7 + 5 + 3 + 1 = 16 = |\Omega|$. Probabilities: $$\sum_x p_X(x) = \frac{7}{16} + \frac{5}{16} + \frac{3}{16} + \frac{1}{16} = \frac{16}{16} = 1 . \checkmark$$ So the complete answer is $$p_X(x) = \begin{cases} 7/16, & x = 1,\\ 5/16, & x = 2,\\ 3/16, & x = 3,\\ 1/16, & x = 4,\\ 0, & \text{otherwise.}\end{cases}$$ All four values are confirmed by exhaustive enumeration of the 16 outcomes in computes/g2_s1.py (pmf_min_frac).

A shortcut worth knowing — count the tail instead. The event $\{X \ge k\} = \{\min(F,S) \ge k\}$ is $\{F \ge k\} \cap \{S \ge k\}$, and each roll has $5-k$ faces that are $\ge k$, so $\{X \ge k\}$ contains $(5-k)^2$ outcomes: $16, 9, 4, 1$ for $k = 1,2,3,4$ (verified as min_ge_k_counts). Since $\{X = k\} = \{X \ge k\} \setminus \{X \ge k+1\}$ and the second set sits inside the first, the counts subtract: $$\#\{X = k\} = (5-k)^2 - (4-k)^2 = \big[(5-k)+(4-k)\big]\big[(5-k)-(4-k)\big] = (9-2k)(1) = 9 - 2k,$$ giving $7,5,3,1$ for $k = 1,2,3,4$ — the same answer with no listing. Hence $p_X(k) = (9-2k)/16$ for $k = 1,2,3,4$.

Fig. 1.1 — L05 slide 4 completed. Left: the sample space with each cell labelled by the value $\min(F,S)$; the shaded L-shape is the event $\{X = 2\}$, five cells of probability $1/16$ each, so $p_X(2) = 5/16$. Interpretation — why the PMF of a minimum slopes down. The picture explains the arithmetic. The event $\{X = k\}$ is an "L" hugging the row and column $k$ inside the sub-square $\{k,\ldots,4\}^2$, and those L's get shorter as $k$ increases: lengths $7,5,3,1$. Equivalently, the minimum of two rolls is pulled toward small values because it takes only one low roll to drag it down but two high rolls to keep it up. That asymmetry — $\mathbf{P}(\min \ge k) = \mathbf{P}(F \ge k)\mathbf{P}(S \ge k)$ is a product of two numbers less than one — is the general reason minima of independent quantities skew low, and maxima (Practice 1.3) skew high.
Gotcha — "min $=2$" is not "both rolls $\ge 2$". The commonest slip here is to compute $\mathbf{P}(F \ge 2, S \ge 2) = (3/4)^2 = 9/16$ and call it $p_X(2)$. That is $\mathbf{P}(X \ge 2)$, not $\mathbf{P}(X = 2)$: it includes $(3,3),(3,4),(4,3),(4,4)$, where the min is $3$ or $4$. The equality version needs the extra clause "and at least one roll equals $2$", or the subtraction $9 - 4 = 5$. Whenever an event is defined by an inequality on a min or max, compute the tail first and difference it — never equate "$=$" with "$\ge$".
Gotcha — the normalization check is not optional. $\sum_x p_X(x) = 1$ is a theorem, so a PMF you derived that fails it is wrong, full stop. It costs one line and catches missed outcomes ($\sum < 1$) and double-counted ones ($\sum > 1$). Every derivation in §§1.3–1.6 ends with this check for exactly that reason.
Practice 1.3 (compare B&T §2.2 Figure 2.2, p. 76). Same experiment — two independent rolls of a fair tetrahedral die — but now let $M = \max(F,S)$. Find the PMF of $M$, check normalization, and give a closed form for $p_M(k)$.
Solution

Range. $\max(f,s) \in \{1,2,3,4\}$, and every value occurs.

Tail counting (the shortcut of Example 1.2, mirrored). $\{M \le k\} = \{F \le k\} \cap \{S \le k\}$ contains $k^2$ outcomes, since each roll has $k$ faces $\le k$: $1, 4, 9, 16$ for $k = 1,2,3,4$. Then $$\#\{M = k\} = k^2 - (k-1)^2 = 2k - 1,$$ giving $1, 3, 5, 7$ for $k = 1,2,3,4$ (confirmed as pmf_max_counts).

Direct check of one value. $\{M = 2\} = \{(1,2),(2,1),(2,2)\}$ — three outcomes — so $p_M(2) = 3/16$, matching B&T Figure 2.2 (p. 76), which works this exact case.

PMF. $$p_M(k) = \frac{2k-1}{16}, \quad k = 1,2,3,4: \qquad p_M(1) = \tfrac1{16},\ p_M(2) = \tfrac3{16},\ p_M(3) = \tfrac5{16},\ p_M(4) = \tfrac7{16}.$$ Check: $1 + 3 + 5 + 7 = 16$, so the probabilities sum to $16/16 = 1$. $\checkmark$

Note the PMF of $M$ is the PMF of $X = \min$ read backwards — a consequence of the symmetry $\max(f,s) = 5 - \min(5-f, 5-s)$ for faces in $\{1,2,3,4\}$.

  • $D = 3$: $(1,4),(4,1)$ — $2$ outcomes.

Dividing by $16$: $$p_D(0) = \tfrac{4}{16} = \tfrac14, \quad p_D(1) = \tfrac{6}{16} = \tfrac38, \quad p_D(2) = \tfrac{4}{16} = \tfrac14, \quad p_D(3) = \tfrac{2}{16} = \tfrac18,$$ matching pmf_d_frac. Practice 1.5. An urn holds $3$ red and $2$ blue balls. Two balls are drawn without replacement, all $\binom{5}{2}$ pairs equally likely. Let $R$ be the number of red balls drawn. Find $p_R(r)$.
Solution

Model. Take $\Omega$ = the set of unordered pairs of balls; $|\Omega| = \binom{5}{2} = 10$, each of probability $1/10$ (G1 counting).

Range. $R \in \{0,1,2\}$.

Count each value by choosing which balls are red and which are blue: $$\#\{R = r\} = \binom{3}{r}\binom{2}{2-r}.$$ $r=0$: $\binom30\binom22 = 1 \cdot 1 = 1$.   $r=1$: $\binom31\binom21 = 3 \cdot 2 = 6$.   $r=2$: $\binom32\binom20 = 3 \cdot 1 = 3$.

PMF. $p_R(0) = 1/10$, $p_R(1) = 6/10 = 3/5$, $p_R(2) = 3/10$. Check: $1 + 6 + 3 = 10$, so the masses sum to $1$. $\checkmark$

This is not a binomial PMF, even though it counts "successes": the draws are not independent and the success probability changes after the first draw ($3/5$ then $2/4$ or $3/4$). It is the hypergeometric PMF. Keep it in mind as the standing counterexample when §1.4 tempts you to call every count binomial.

1.3 Two starter PMFs: Bernoulli and discrete uniform

Four PMFs recur so often that they are named. Two are almost trivial; deriving them anyway fixes the recipe.

Definition (Bernoulli; B&T §2.2 p. 75). Toss a coin that comes up heads with probability $p$ and tails with probability $1-p$, where $0 \le p \le 1$. Let $X = 1$ if heads and $X = 0$ if tails. Then $X$ is a Bernoulli random variable with parameter $p$, with PMF $$p_X(x) = \begin{cases} p, & x = 1,\\ 1 - p, & x = 0,\\ 0, & \text{otherwise.}\end{cases}$$

Derivation. Here $\Omega = \{H, T\}$ with $\mathbf{P}(\{H\}) = p$ and $\mathbf{P}(\{T\}) = 1-p$, and $X(H) = 1$, $X(T) = 0$. Applying the recipe: the range is $\{0,1\}$; the outcomes with $X = 1$ are $\{H\}$, whose probability is $p$; the outcomes with $X = 0$ are $\{T\}$, whose probability is $1-p$. Check: $p + (1-p) = 1$. $\checkmark$

Interpretation — the indicator of an event. Nothing about coins is essential. Given any event $A$ in any model, the indicator random variable $$\mathbf{1}_A(\omega) = \begin{cases} 1, & \omega \in A,\\ 0, & \omega \notin A\end{cases}$$ is Bernoulli with parameter $p = \mathbf{P}(A)$, since $\{\mathbf{1}_A = 1\} = A$ and $\{\mathbf{1}_A = 0\} = A^c$, of probabilities $\mathbf{P}(A)$ and $1 - \mathbf{P}(A)$. So Bernoulli is the bridge between G1's language of events and G2's language of numbers: every yes/no question becomes a $\{0,1\}$-valued random variable. The book's examples (B&T §2.2, p. 76) are a telephone line that is free or busy, a person healthy or sick, and a voter for or against a proposal. This is also why binomial counts (§1.4) are so common — a count of successes is a sum of indicators.
Definition (discrete uniform; L05 slide 6 figure, B&T §2.2). Let $a \le b$ be integers, and let $X$ take each of the $n = b - a + 1$ values $a, a+1, \ldots, b$ with equal probability. Then $X$ is discrete uniform on $\{a,\ldots,b\}$, with PMF $$p_X(k) = \begin{cases} \dfrac{1}{b-a+1}, & k = a, a+1, \ldots, b,\\[4pt] 0, & \text{otherwise.}\end{cases}$$ L05 slide 6 uses the special case $a = 0$, $b = n$, where each of the $n+1$ values $0,1,\ldots,n$ has mass $1/(n+1)$.

Derivation. "Each value equally likely" means $p_X(k) = c$, the same constant $c$, for all $n = b-a+1$ values in the range. Normalization forces $$1 = \sum_{k=a}^{b} p_X(k) = \sum_{k=a}^{b} c = n c \quad \Longrightarrow \quad c = \frac1n = \frac{1}{b-a+1},$$ where the middle step just says that adding the same number $c$ to itself $n$ times gives $nc$. So the constant is not a choice — normalization pins it. For $a=0,b=n$: $c = 1/(n+1)$, e.g. $n = 5$ gives $c = 1/6 \approx 0.166667$ (unif_0_5_mass).

Gotcha — count the values, not the gap. The number of integers from $a$ to $b$ inclusive is $b - a + 1$, not $b - a$. On $\{0,1,\ldots,n\}$ the mass is $1/(n+1)$, not $1/n$ — the value $0$ is a value. Off-by-one here silently breaks normalization and every mean and variance downstream.
Gotcha — a uniform $\Omega$ does not make $X$ uniform. In Example 1.2 all $16$ outcomes were equally likely, yet $X = \min(F,S)$ had masses $7/16, 5/16, 3/16, 1/16$ — very far from uniform. Uniformity is a property of the PMF of $X$, i.e. of how many outcomes each value collects, not of the underlying law on $\Omega$.
Practice 1.6. A fair six-sided die is rolled once; $X$ is the face shown. (a) Give $p_X$. (b) Let $Y = \mathbf{1}_{\{X \text{ is even}\}}$. Give $p_Y$ and name its distribution.
Solution

(a) $X$ is discrete uniform on $\{1,\ldots,6\}$, so $n = 6 - 1 + 1 = 6$ and $p_X(k) = 1/6$ for $k = 1,\ldots,6$, zero otherwise. Check: $6 \times \tfrac16 = 1$. $\checkmark$

(b) $\{Y = 1\} = \{2,4,6\}$, three outcomes of probability $1/6$ each, so $p_Y(1) = 3/6 = 1/2$; and $p_Y(0) = 1 - 1/2 = 1/2$. $Y$ is Bernoulli with parameter $p = 1/2$ — the indicator of the event "even face". Note that a function of a uniform random variable is generally not uniform on its range; here it happens to be, because the event and its complement have equal probability.

Practice 1.7. $X$ is discrete uniform on $\{3,4,\ldots,17\}$. (a) What is $p_X(10)$? (b) What is $\mathbf{P}(X \ge 12)$? (c) What is $\mathbf{P}(X \text{ is a multiple of } 5)$?
Solution

(a) The number of values is $17 - 3 + 1 = 15$, so $p_X(k) = 1/15$ for each $k$ in range; in particular $p_X(10) = 1/15 \approx 0.0667$.

(b) By the $\mathbf{P}(X \in S)$ formula with $S = \{12,13,\ldots,17\}$, which has $17-12+1 = 6$ elements: $$\mathbf{P}(X \ge 12) = \sum_{k=12}^{17} \frac{1}{15} = \frac{6}{15} = \frac{2}{5} = 0.4.$$

(c) The multiples of $5$ in $\{3,\ldots,17\}$ are $5, 10, 15$ — three values — so the probability is $3/15 = 1/5 = 0.2$.

1.4 The binomial PMF

Now the two PMFs that carry real content. Both come from repeated independent tosses of the same coin; they differ only in what you count and when you stop.

Example 1.3 (L05 slide 5, with the omitted steps restored) — number of heads in $n = 4$ tosses.

Setup. A coin with $\mathbf{P}(H) = p$ is tossed $n = 4$ times, independently. Let $X$ be the number of heads. The sample space is the set of length-$4$ sequences over $\{H,T\}$, $|\Omega| = 2^4 = 16$ (verified as n4_total_sequences). Note these $16$ outcomes are not equally likely unless $p = 1/2$.

Step 1 — probability of one sequence. Take $HHTT$. It is the intersection of four single-toss events (toss 1 is $H$, toss 2 is $H$, toss 3 is $T$, toss 4 is $T$), which are independent by assumption, so by the multiplication rule for independent events (G1 §3) $$\mathbf{P}(HHTT) = \mathbf{P}(H)\,\mathbf{P}(H)\,\mathbf{P}(T)\,\mathbf{P}(T) = p \cdot p \cdot (1-p) \cdot (1-p) = p^2 (1-p)^2 .$$ The same computation applies to any sequence with two heads and two tails — multiplication is commutative, so only the counts of $H$'s and $T$'s matter, not their order. Hence every one of the six sequences below has probability $p^2(1-p)^2$. This is the line the slide omits.

Step 2 — collect the outcomes with $X = 2$. The slide lists all six: $$\{X = 2\} = \{HHTT,\ HTHT,\ HTTH,\ THHT,\ THTH,\ TTHH\},$$ confirmed by exhaustive enumeration in computes/g2_s1.py (n4_k2_sequences).

Step 3 — add. Distinct sequences are disjoint events, so additivity gives $$p_X(2) = \mathbf{P}(HHTT) + \mathbf{P}(HTHT) + \mathbf{P}(HTTH) + \mathbf{P}(THHT) + \mathbf{P}(THTH) + \mathbf{P}(TTHH)$$ $$= \underbrace{p^2(1-p)^2 + \cdots + p^2(1-p)^2}_{6 \text{ equal terms}} = 6\,p^2(1-p)^2 .$$

Step 4 — recognize the $6$. The six sequences are exactly the ways to choose which two of the four toss positions are heads, and by G1's counting rules the number of $2$-element subsets of a $4$-element set is $$\binom{4}{2} = \frac{4!}{2!\,2!} = \frac{24}{2 \cdot 2} = 6 . \checkmark$$ So $p_X(2) = \binom{4}{2} p^2(1-p)^2$, the slide's last line — and now the $6$ is derived, not observed.

Numbers. $p = 0.5$: $6(0.25)(0.25) = 0.375$.   $p = 0.6$: $6(0.36)(0.16) = 0.3456$.   $p = 0.3$: $6(0.09)(0.49) = 0.2646$. (All from binom_n4_k2_*.)

Definition / Theorem (binomial PMF; L05 slide 5, B&T §2.2 p. 77). Toss a coin with $\mathbf{P}(H) = p$ a fixed number $n$ of times, independently, and let $X$ be the number of heads. Then $X$ is binomial with parameters $n$ and $p$, and $$p_X(k) \;=\; \binom{n}{k} p^k (1-p)^{n-k}, \qquad k = 0, 1, \ldots, n,$$ where $n$ is the number of trials, $p$ the success probability per trial, $k$ the number of successes, and $\binom{n}{k} = \frac{n!}{k!\,(n-k)!}$ the number of ways to choose which $k$ of the $n$ trials succeed.
Derivation of the general formula (the jump the slide asserts)

Step 1 — the sample space. An outcome is a sequence $\omega = (\omega_1,\ldots,\omega_n)$ with each $\omega_i \in \{H,T\}$; there are $2^n$ of them. $X(\omega)$ is the number of $H$'s in $\omega$, so the range of $X$ is $\{0,1,\ldots,n\}$.

Step 2 — probability of one sequence with exactly $k$ heads. Fix such a sequence. It specifies the result of each of the $n$ independent tosses, so its probability is the product of $n$ per-toss probabilities: $k$ factors of $p$ (one for each head) and $n-k$ factors of $1-p$ (one for each tail). Regrouping the product (commutativity of multiplication), $$\mathbf{P}(\omega) = p^{k}(1-p)^{n-k} \qquad \text{for every } \omega \text{ with } k \text{ heads.}$$ The key point: this depends on $k$ only, not on where the heads are.

Step 3 — count such sequences. A sequence with exactly $k$ heads is determined by the set of positions holding the heads, a $k$-element subset of $\{1,\ldots,n\}$; conversely each such subset gives one sequence. The correspondence is one-to-one, so the number of sequences equals the number of $k$-subsets, which G1 computed as $\binom{n}{k} = \frac{n!}{k!(n-k)!}$.

Step 4 — add. The event $\{X = k\}$ is the union of those $\binom{n}{k}$ distinct sequences, which are disjoint singleton events, so by additivity $$p_X(k) = \sum_{\omega : X(\omega) = k} \mathbf{P}(\omega) = \underbrace{\binom{n}{k}}_{\text{how many}} \times \underbrace{p^k(1-p)^{n-k}}_{\text{each one's probability}} .$$ This is the general formula. For $n=4$, $k=2$ it returns $6p^2(1-p)^2$, matching Example 1.3. $\blacksquare$

Step 5 — normalization check. By the binomial theorem $\sum_{k=0}^{n}\binom{n}{k}a^k b^{n-k} = (a+b)^n$, applied with $a = p$ and $b = 1-p$: $$\sum_{k=0}^{n} \binom{n}{k}p^k(1-p)^{n-k} = \big(p + (1-p)\big)^n = 1^n = 1 . \checkmark$$ Numerically confirmed to $10^{-12}$ for $(n,p) = (4,0.5), (4,0.6), (10,0.35), (12,0.2), (25,0.5)$ in computes/g2_s1.py (binom_norm_*).

Interpretation — "how many ways" $\times$ "how likely each way". Every binomial probability is a product of a combinatorial factor and a probabilistic factor. $p^k(1-p)^{n-k}$ is the probability of one specific script — heads exactly here, tails exactly there. $\binom{n}{k}$ counts how many scripts produce the same headline "$k$ heads". Independence is what makes the probabilistic factor identical across scripts, which is what lets you multiply rather than sum a messy list. Take independence away (draw balls without replacement, as in Practice 1.5) and different scripts have different probabilities; the factorization collapses and the answer is hypergeometric, not binomial.
Interpretation — the shape of the binomial PMF (B&T §2.2 Figure 2.3). Panel (c) of Fig. 1.2 shows $n = 10$ at $p = 0.2, 0.5, 0.8$. At $p = 1/2$ the PMF is symmetric about $n/2 = 5$, because swapping the roles of $H$ and $T$ maps $k \mapsto n-k$ and leaves the formula unchanged. For $p < 1/2$ the mass is pulled toward $0$, for $p > 1/2$ toward $n$, and the peak sits near $np$ — the mean, derived in §2. The $p = 0.2$ and $p = 0.8$ curves are exact mirror images, since $\binom{n}{k}p^k(1-p)^{n-k}$ with $p \to 1-p$, $k \to n-k$ is the same number.
Gotcha — the three binomial preconditions. The formula requires all three: (i) the number of trials $n$ is fixed in advance, not determined by the results; (ii) the trials are independent; (iii) the success probability $p$ is the same on every trial. Drop (i) and you get a geometric-type problem (§1.5); drop (ii) or (iii) and you get something else entirely (Practice 1.5). Ask these three questions before writing $\binom{n}{k}$.
Gotcha — $\binom{n}{k}p^k(1-p)^{n-k}$ is not $\binom{n}{k}p^k$. Forgetting the $(1-p)^{n-k}$ factor is the single most common binomial error. The exponents must add to $n$: every trial contributes exactly one factor, either a $p$ or a $1-p$. If your exponents do not sum to the number of trials, the expression cannot be a probability of anything.
Practice 1.8. A biased coin with $\mathbf{P}(H) = 0.3$ is tossed $5$ times independently. Find the probability of exactly $2$ heads, showing every factor.
Solution

This is binomial with $n = 5$, $p = 0.3$, $k = 2$: $$p_X(2) = \binom{5}{2}(0.3)^2(0.7)^{3}.$$ Factor by factor: $\binom{5}{2} = \frac{5!}{2!\,3!} = \frac{120}{2 \cdot 6} = 10$; $(0.3)^2 = 0.09$; $(0.7)^3 = 0.343$. So each of the $10$ qualifying sequences has probability $0.09 \times 0.343 = 0.03087$, and $$p_X(2) = 10 \times 0.03087 = 0.3087 .$$ (All four intermediate values are binom_n5_p03_k2_parts in computes/g2_s1.py.) Exponent check: $2 + 3 = 5 = n$. $\checkmark$

Practice 1.9. A fair coin ($p = 1/2$) is tossed $3$ times. Write the entire PMF of the number of heads $X$ as exact fractions, and verify normalization.
Solution

With $p = 1/2$, $p^k(1-p)^{3-k} = (1/2)^3 = 1/8$ for every $k$ — all $2^3 = 8$ sequences are equally likely — so the PMF is just the count of subsets divided by $8$: $$p_X(k) = \binom{3}{k}\Big(\tfrac12\Big)^3 = \frac{\binom{3}{k}}{8}, \qquad \binom30 = 1,\ \binom31 = 3,\ \binom32 = 3,\ \binom33 = 1 .$$ So $p_X(0) = 1/8$, $p_X(1) = 3/8$, $p_X(2) = 3/8$, $p_X(3) = 1/8$ (binom_n3_p05_table). Check: $\tfrac18 + \tfrac38 + \tfrac38 + \tfrac18 = \tfrac88 = 1$. $\checkmark$ The symmetry $p_X(k) = p_X(3-k)$ is the $p = 1/2$ mirror symmetry noted above.

Practice 1.10. With $n = 10$ and $p = 0.35$, use $\mathbf{P}(X \in S) = \sum_{x \in S} p_X(x)$ and the complement rule to find $\mathbf{P}(X \ge 1)$ without summing ten terms.
Solution

$\{X \ge 1\}$ is the complement of $\{X = 0\}$, so by the complement rule (G1 §1.2), $$\mathbf{P}(X \ge 1) = 1 - p_X(0) = 1 - \binom{10}{0}(0.35)^0(0.65)^{10} = 1 - (0.65)^{10}.$$ From binom_n10_p035_table, $p_X(0) = 0.013463$, so $\mathbf{P}(X \ge 1) = 1 - 0.013463 = 0.986537$. Summing $p_X(1) + \cdots + p_X(10)$ gives the same number, but with nine more terms — always look for the complement when the event is "at least one".

1.5 The geometric PMF

The binomial fixes $n$ and counts successes. Invert the question — fix the number of successes at one and count trials — and the geometric PMF appears.

Example 1.4 (L05 slide 3, with the omitted steps restored) — number of tosses until the first head.

Setup. Toss a coin repeatedly and independently, with $\mathbf{P}(H) = p > 0$ on each toss. Let $X$ be the number of tosses up to and including the first head. The requirement $p > 0$ is what guarantees a head eventually appears; see the Gotcha below.

Step 1 — the range. $X$ can be $1$ (head immediately), $2$, $3$, …, with no upper bound: $X \in \{1,2,3,\ldots\}$, a countably infinite range. This is the first PMF in this section with infinitely many values.

Step 2 — collect the outcomes with $X = k$. "$X = k$" says the first head arrives on toss $k$, which pins down the first $k$ tosses exactly: tosses $1$ through $k-1$ are tails (otherwise the first head would have come earlier) and toss $k$ is a head. So there is only one qualifying pattern for the first $k$ tosses, $$\{X = k\} = \{\underbrace{TT\cdots T}_{k-1 \text{ tails}}H\},$$ which is the slide's $\mathbf{P}(TT\cdots TH)$. Unlike the binomial, no counting factor appears — there is exactly one way for the first head to arrive on toss $k$.

Step 3 — its probability, by independence. The pattern is an intersection of $k$ independent single-toss events, so its probability is the product of their probabilities: $k-1$ factors of $\mathbf{P}(T) = 1-p$ and one factor of $\mathbf{P}(H) = p$, $$\mathbf{P}(\underbrace{TT\cdots T}_{k-1}H) = \underbrace{(1-p)(1-p)\cdots(1-p)}_{k-1 \text{ factors}} \cdot p = (1-p)^{k-1}p .$$ This multiplication is the [derivation gap] the slide leaves implicit. Hence $$\boxed{\,p_X(k) = (1-p)^{k-1}p, \qquad k = 1,2,3,\ldots\,}$$ and $p_X(k) = 0$ for all other $k$ (including $k = 0$: you cannot see a head in zero tosses).

Numbers ($p = 0.3$, from geom_p03_table). $p_X(1) = 0.3$, $p_X(2) = 0.7 \times 0.3 = 0.21$, $p_X(3) = 0.49 \times 0.3 = 0.147$, $p_X(4) = 0.1029$, $p_X(5) = 0.07203$, … Each term is $0.7$ times the previous one.

Normalization: $\sum_{k=1}^{\infty}(1-p)^{k-1}p = 1$ — the check the slide only implies

Write $q = 1-p$ for the tail probability, so $0 \le q < 1$ (here $q < 1$ because $p > 0$). Substituting $j = k-1$, so that $j$ runs over $0,1,2,\ldots$ as $k$ runs over $1,2,3,\ldots$: $$\sum_{k=1}^{\infty} (1-p)^{k-1}p \;=\; p\sum_{j=0}^{\infty} q^{\,j}.$$ The constant $p$ comes out of the sum because it multiplies every term.

Step 1 — the finite geometric sum. Let $S_N = \sum_{j=0}^{N-1} q^{\,j} = 1 + q + q^2 + \cdots + q^{N-1}$. Multiply by $q$ and subtract: $$S_N - qS_N = (1 + q + \cdots + q^{N-1}) - (q + q^2 + \cdots + q^{N}) = 1 - q^{N},$$ because every term except the leading $1$ and the trailing $q^N$ cancels in pairs (telescoping). Factoring the left side, $(1-q)S_N = 1 - q^N$, and since $q < 1$ we may divide by $1 - q \neq 0$: $$S_N = \frac{1 - q^{N}}{1 - q}.$$ Numerical check with $q = 0.7$, $N = 10$: direct summation gives $3.23917492$, and $(1 - 0.7^{10})/0.3 = 3.23917492$ (geom_series_partial_N10_q0.7). $\checkmark$

Step 2 — let $N \to \infty$. Since $0 \le q < 1$, $q^N \to 0$ (repeatedly multiplying by a number below $1$ drives the product to zero). Therefore $$\sum_{j=0}^{\infty} q^{\,j} = \lim_{N\to\infty} S_N = \frac{1 - 0}{1-q} = \frac{1}{1-q}.$$ With $q = 0.7$ this is $1/0.3 = 3.33333333$ (geom_series_limit_q0.7). $\checkmark$

Step 3 — put it together. Since $1 - q = 1 - (1-p) = p$, $$\sum_{k=1}^{\infty} p_X(k) = p \cdot \frac{1}{1-q} = p \cdot \frac{1}{p} = 1 . \checkmark$$ So the geometric PMF is a legitimate PMF (B&T §2.2, p. 78). Numerically, summing $20\,000$ terms gives $1.0$ to $10^{-12}$ for $p = 0.3, 0.5, 0.1$ (geom_norm_*); the partial sums for $p=0.3$ climb $0.3,\ 0.51,\ 0.657,\ 0.83193,\ 0.971752,\ 0.999202$ at $k \le 1,2,3,5,10,20$ (geom_p03_partial_sums).

Bonus — the tail probability. The same series gives, for any integer $k \ge 0$, $$\mathbf{P}(X > k) = \sum_{i=k+1}^{\infty}(1-p)^{i-1}p = p(1-p)^{k}\sum_{j=0}^{\infty}(1-p)^{j} = p(1-p)^k \cdot \frac1p = (1-p)^k,$$ where the middle step factors $(1-p)^k$ out of every term. This also follows in one line without any series: $\{X > k\}$ says the first $k$ tosses are all tails, an event of probability $(1-p)^k$ by independence. Check for $p = 0.3$, $k = 3$: series sum $0.343 = 0.7^3$. $\checkmark$ (geom_tail_p0.3_k3.)

Interpretation — constant decay and memorylessness. Consecutive masses have a constant ratio, $p_X(k+1)/p_X(k) = 1-p$: each extra toss you must wait is $(1-p)$ times as likely as the one before, which is why panel (d) of Fig. 1.2 is a clean exponential staircase. The deeper statement behind it is memorylessness: given that the first $k$ tosses were tails, the conditional probability of needing $j$ more is $$\mathbf{P}(X > k + j \mid X > k) = \frac{\mathbf{P}(X > k+j)}{\mathbf{P}(X > k)} = \frac{(1-p)^{k+j}}{(1-p)^{k}} = (1-p)^{j} = \mathbf{P}(X > j),$$ using the definition of conditional probability (G1 §2) and the fact that $\{X > k+j\} \subseteq \{X > k\}$. A coin that has just produced ten tails is not "due" for a head — the process starts fresh. This property is taken up properly in L06–L07.
Gotcha — the exponent is $k-1$, not $k$. $p_X(k) = (1-p)^{k-1}p$: there are $k-1$ tails and one head among the $k$ tosses, so the exponents must add to $k$. Writing $(1-p)^k p$ would make the masses sum to $(1-p)$ instead of $1$ — the normalization check catches it instantly.
Gotcha — geometric random variables start at $1$, and the convention varies. Here $X$ counts tosses, so $X \ge 1$ and $p_X(0) = 0$. Many texts instead count failures before the first success, giving $Y = X - 1$ with $p_Y(k) = (1-p)^k p$ for $k = 0,1,2,\ldots$. Both are "the geometric distribution"; they differ by $1$, and so do their means ($1/p$ versus $(1-p)/p$). Always state which you mean. (Software is a useful sanity check here: both scipy.stats.geom and numpy.random.geometric use the "number of trials" convention — geom.pmf(0, p) is $0$ and geom.pmf(1, p) is $p$ — whereas the shifted "number of failures" version is scipy.stats.nbinom(1, p), whose mass at $0$ is $p$.) 6.041 uses the "number of trials" version of L05 slide 3.
Gotcha — $p > 0$ is a real hypothesis. If $p = 0$ every mass is $0$ and the PMF does not normalize: $X$ is not a well-defined (finite-valued) random variable, since no head ever comes. The slide's "$\mathbf{P}(H) = p > 0$" is doing work. Conversely for any $p>0$ the total mass is exactly $1$, which says the first head arrives in finitely many tosses with probability $1$, however small $p$ is.
Practice 1.11. With $p = 0.3$, compute (a) $\mathbf{P}(X = 4)$, (b) $\mathbf{P}(X > 3)$, (c) $\mathbf{P}(2 \le X \le 4)$.
Solution

(a) $p_X(4) = (0.7)^{3}(0.3) = 0.343 \times 0.3 = 0.1029$.

(b) $\mathbf{P}(X > 3) = (1-p)^3 = (0.7)^3 = 0.343$ — the first three tosses are all tails.

(c) By $\mathbf{P}(X \in S) = \sum_{x\in S}p_X(x)$ with $S = \{2,3,4\}$: $$0.21 + 0.147 + 0.1029 = 0.4599 .$$ Cross-check with tails: $\mathbf{P}(2 \le X \le 4) = \mathbf{P}(X > 1) - \mathbf{P}(X > 4) = 0.7 - 0.7^4 = 0.7 - 0.2401 = 0.4599$. $\checkmark$ (Values from geom_p03_table.)

Practice 1.12. A coin with $\mathbf{P}(H) = 0.4$ is tossed until a head appears or three tosses have been made, whichever comes first. Let $N$ be the number of tosses actually made. Find $p_N$, and explain why it is not geometric.
Solution

Range: $N \in \{1,2,3\}$ — the experiment stops at three tosses no matter what.

$N = 1$: the first toss is a head: $p_N(1) = p = 0.4$.

$N = 2$: tail then head: $p_N(2) = (1-p)p = 0.6 \times 0.4 = 0.24$.

$N = 3$: the first two tosses are tails; the third toss happens regardless of its result, so this event is just $\{TT\ast\}$: $p_N(3) = (1-p)^2 = 0.36$. Note it is not $(1-p)^2 p = 0.144$ — that would be the probability of a head on toss 3, but $N = 3$ whether toss 3 is a head or a tail.

Check: $0.4 + 0.24 + 0.36 = 1$. $\checkmark$ (trunc_geom_p04.)

Why not geometric: a geometric random variable has infinite range, and its masses decay by a constant factor $1-p$ forever. Here the range is truncated at $3$, and the last mass is inflated ($0.36$ instead of $0.144$) because it absorbs the entire remaining tail $\mathbf{P}(X \ge 3) = 0.36$ of the untruncated geometric. Truncating a geometric never yields another geometric.

Practice 1.13. Each attempt at sending a packet succeeds independently with probability $p = 0.2$. Let $X$ be the number of attempts until the first success. How many attempts $k$ are needed before $\mathbf{P}(X \le k) \ge 0.9$?
Solution

Use the tail: $\mathbf{P}(X \le k) = 1 - \mathbf{P}(X > k) = 1 - (0.8)^k$. Require $$1 - (0.8)^k \ge 0.9 \iff (0.8)^k \le 0.1 \iff k \ln 0.8 \le \ln 0.1 \iff k \ge \frac{\ln 0.1}{\ln 0.8},$$ the inequality flipping at the last step because $\ln 0.8 < 0$. Numerically $\ln 0.1 = -2.302585$ and $\ln 0.8 = -0.223144$, so $k \ge 10.3189$, i.e. $k = 11$. Verify: $(0.8)^{10} = 0.107374$, giving $\mathbf{P}(X \le 10) = 0.892626 < 0.9$; $(0.8)^{11} = 0.085899$, giving $\mathbf{P}(X \le 11) = 0.914101 \ge 0.9$. $\checkmark$ So $11$ attempts. 1.6 Choosing among the named PMFs

All four PMFs sit side by side below. Read them as four different answers to "what number is the experiment producing?".

Fig. 1.2 — The four named discrete PMFs of this section (geometric: L05 slide 3; binomial: L05 slide 5; discrete uniform: L05 slide 6 figure; Bernoulli: B&T §2.2 p. 75; cf. B&T §2.2 Figures 2.3 and 2.4). (a) Bernoulli($0.3$): all mass on $\{0,1\}$. (b) discrete uniform on $\{0,\ldots,8\}$: flat at $1/(n+1) = 1/9$. (c) binomial($10,p$): finite range $\{0,\ldots,10\}$, peak near $np$, symmetric only at $p = 1/2$. (d) geometric($p$): infinite range $\{1,2,\ldots\}$, each mass exactly $(1-p)$ times the previous one.
Recipe — which PMF is this? (decision guide; L05 slides 3, 5, 6 · B&T §2.2, which supplies the Bernoulli).
  1. Is there just one trial with a yes/no result, and does $X$ flag it $0$/$1$? → Bernoulli($p$), $p_X(1) = p$, $p_X(0) = 1-p$. (Also the case whenever $X$ is the indicator of an event.)
  2. Does $X$ take finitely many values that are equally likely by symmetry? → discrete uniform on $\{a,\ldots,b\}$, $p_X(k) = 1/(b-a+1)$.
  3. Are there repeated independent trials with the same success probability $p$? Then ask when the experiment stops:
    • stops after a preset number $n$ of trials, and $X$ counts the successes → binomial($n,p$), $p_X(k) = \binom{n}{k}p^k(1-p)^{n-k}$, $k = 0,\ldots,n$;
    • stops at the first success, and $X$ counts the trials → geometric($p$), $p_X(k) = (1-p)^{k-1}p$, $k = 1,2,\ldots$
  4. Otherwise — trials dependent (sampling without replacement), $p$ varying between trials, values unequally likely, or a truncated/mixed stopping rule — do not force a name. Use the general recipe of §1.2: collect the outcomes with $X = x$, add their probabilities, and check that the masses sum to $1$.
Fast structural test: a finite range that ends at a number appearing in the problem statement points to binomial or uniform; an infinite range $1,2,3,\ldots$ points to geometric; a two-point range points to Bernoulli.

Interpretation — binomial and geometric are the same coin, read two ways. Both models are an unlimited supply of independent $p$-coins. The binomial fixes the horizon and asks about the count; the geometric fixes the count (at one success) and asks about the horizon. Their PMFs reflect that: the binomial has a combinatorial factor $\binom{n}{k}$ because many arrangements give $k$ successes in $n$ trials, while the geometric has no such factor because exactly one arrangement puts the first success at trial $k$. The two are linked by a one-line identity you should be able to reproduce: $\mathbf{P}(\text{geometric } X > n) = (1-p)^n = \mathbf{P}(\text{binomial}(n,p) = 0)$ — "no success in the first $n$ trials" is the same event in both readings.

Practice 1.14. For each experiment, name the PMF (with its parameters) or explain why none of the four applies. (a) The number of sixes in $20$ rolls of a fair die. (b) The number of rolls of a fair die until the first six. (c) The face shown on one roll of a fair die. (d) The number of aces in a $5$-card poker hand dealt from a standard deck. (e) Whether a randomly chosen 6.041 student passed the quiz.
Solution

(a) Binomial($20, 1/6$): $n = 20$ trials fixed in advance, independent, "six" has the same probability $1/6$ each roll, $X$ counts successes. $p_X(k) = \binom{20}{k}(1/6)^k(5/6)^{20-k}$.

(b) Geometric($1/6$): independent trials, same $p = 1/6$, stop at the first success, $X$ counts trials. $p_X(k) = (5/6)^{k-1}(1/6)$, $k \ge 1$.

(c) Discrete uniform on $\{1,\ldots,6\}$: six equally likely values, mass $1/6$ each.

(d) None of the four. The cards are dealt without replacement, so the draws are dependent and the probability of an ace changes as cards leave the deck. Use the general recipe: $p_X(k) = \binom{4}{k}\binom{48}{5-k}/\binom{52}{5}$ (hypergeometric, as in Practice 1.5).

(e) Bernoulli($p$) with $p$ = the fraction of students who passed — the indicator of the event "passed".

Practice 1.15. A quality inspector tests items one at a time, independently; each item is defective with probability $0.05$. (a) In a batch of $20$ tested items, what is the probability that exactly one is defective? (b) What is the probability that the first defective item is the $20$th tested? (c) Which is larger, and why does that make sense?
Solution

(a) Binomial with $n = 20$, $p = 0.05$, $k = 1$: $$\binom{20}{1}(0.05)^1(0.95)^{19} = 20 \times 0.05 \times 0.377354 = 0.377354 .$$ (Here $(0.95)^{19} = 0.377354$ and the factor $20 \times 0.05 = 1$ makes the answer equal to it.)

(b) Geometric with $p = 0.05$, $k = 20$: $(0.95)^{19}(0.05) = 0.377354 \times 0.05 = 0.018868$.

(c) Part (a) is about $20$ times larger. Both events involve exactly one defective among $20$ items, but (a) allows the defective to be in any of the $20$ positions — $\binom{20}{1} = 20$ arrangements — while (b) insists it be last, one arrangement, and additionally requires the other $19$ to come first. Same per-sequence probability $(0.05)(0.95)^{19}$, twenty times as many sequences. This is precisely the $\binom{n}{k}$-versus-no-factor contrast of §1.6.

§1 cheatsheet.
  • Random variable: a function $X : \Omega \to \mathbb{R}$. Randomness is in $\omega$, not in $X$. Many random variables can live on one $\Omega$; $g(X)$ is again a random variable. Discrete = finite or countable range. Upper case $X$ = the function, lower case $x$ = a value, "$X = x$" = the event $\{\omega : X(\omega) = x\}$.
  • PMF: $p_X(x) = \mathbf{P}(X = x) = \mathbf{P}(\{\omega : X(\omega) = x\})$, with $p_X(x) \ge 0$ and $\sum_x p_X(x) = 1$ (both proved from the G1 axioms via the partition $\{X = x\}$ of $\Omega$). More generally $\mathbf{P}(X \in S) = \sum_{x \in S} p_X(x)$.
  • Recipe: for each value $x$ — collect the outcomes with $X(\omega) = x$, add their probabilities; repeat; check that the total is $1$.
  • Worked slide example: two fair tetrahedral rolls, $X = \min(F,S)$: $p_X(k) = (9-2k)/16$, i.e. $7/16,\,5/16,\,3/16,\,1/16$; in particular $p_X(2) = 5/16 = 0.3125$.
  • Bernoulli($p$): $p_X(1) = p$, $p_X(0) = 1-p$. Any indicator $\mathbf{1}_A$ is Bernoulli($\mathbf{P}(A)$).
  • Discrete uniform on $\{a,\ldots,b\}$: $p_X(k) = 1/(b-a+1)$ — count the values inclusively.
  • Binomial($n,p$): $p_X(k) = \binom{n}{k}p^k(1-p)^{n-k}$, $k = 0,\ldots,n$. "How many arrangements" $\times$ "probability of one arrangement". Normalizes by the binomial theorem. Needs fixed $n$, independence, constant $p$.
  • Geometric($p$), $p>0$: $p_X(k) = (1-p)^{k-1}p$, $k = 1,2,\ldots$ — one arrangement only. Normalizes by $\sum_{j\ge0}q^j = 1/(1-q)$ with $q = 1-p$. Tail: $\mathbf{P}(X > k) = (1-p)^k$; memoryless.
  • Choosing: two values → Bernoulli; equally likely finite values → uniform; repeated independent trials with $n$ fixed → binomial; repeated independent trials stopping at the first success → geometric; anything else → the general recipe.
